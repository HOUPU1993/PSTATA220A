1线性模型的假设

课件第 2 页：Linear Modeling Assumption + 手写

📝 课件原文

假设均值是 $X$ 的线性函数：$E(Y\mid X) = X\beta$。要对回归系数做不确定性量化，还需要额外的假设：

  1. 响应之间不相关。时间序列、空间数据里经常不成立；替代方案：聚类稳健标准误、广义最小二乘（GLS）。
  2. 残差方差恒定（同方差，homoskedasticity）。替代方案：稳健标准误、加权最小二乘（WLS）。
  3. 正态。参数化的假设检验和置信区间需要它。
✍️ 手写
  • $E(Y\mid X) = X\beta$ 圈起来：Model is correct（模型形式是对的）。
  • 假设 1 旁边：$\mathrm{Cor}(Y_i, Y_j\mid X) = 0$ $\Rightarrow$ $\mathrm{Var}(Y\mid X)$ is diagonal（协方差矩阵是对角的）。
  • 假设 2 旁边画了一张喇叭形散点图，标 Heterosked.（异方差）；下面写 1 + 2 $\Rightarrow$ $\mathrm{Var}(Y\mid X) = \sigma^2 I$。
  • 假设 3 旁边：$Y \sim N(X\beta, \sigma^2)$。
  • 最下面一段：Assumptions buy us information about the distribution of $\hat\beta$. Enables CI construction and hypothesis testing. But $E[\hat\beta\mid X] = \beta$ even if 1, 2 & 3 don't hold!

（课件上编号是 1、3、4，老师手写改成了 1、2、3。）

最后那句话是这一讲的主线

只要 $E(Y\mid X) = X\beta$，就有 $E[\hat\beta\mid X] = (X^TX)^{-1}X^TE[Y\mid X] = (X^TX)^{-1}X^TX\beta = \beta$，完全不需要假设 1、2、3。这三条只影响「$\hat\beta$ 有多不确定」：方差公式 $\sigma^2(X^TX)^{-1}$ 要用 1、2，$t$ 和 $F$ 的精确分布要用 3。所以假设出问题时，估计值本身通常还能用，要修的是标准误和检验。

2Added-variable 图：检查线性

课件第 3–6 页：Added variable plot + 手写

📝 课件原文

对每个固定的 $j$：

  • 用除 $x_j$ 以外的所有 $x$ 回归 $y$，取残差 $\hat\epsilon_{y_j}$：去掉了其他 $X$ 效应的 $y$。
  • 用除 $x_j$ 以外的所有 $x$ 回归 $x_j$，取残差 $\hat\epsilon_{x_j}$：去掉了其他 $X$ 效应的 $x_j$。
  • 画 $\hat\epsilon_{y_j}$ 对 $\hat\epsilon_{x_j}$ 的图，找非线性的模式、离群值和强影响点。

为什么这张图有道理？回顾 FWL 定理（L03 §5）。

✍️ 手写
  • 标题旁："Test for linearity"（检查线性）。
  • $j \in 1, \dots, p$ predictors；两次回归分别是 lm(y ~ X_{-j}) 和 lm(X_j ~ X_{-j})（$X_{-j}$ 表示去掉第 $j$ 列）。
  • 在 FWL 定理里，把 $X_1$ 改写成 $X_{-j}$、$X_2$ 改写成 $X_j$；$P^\perp_{X_{-j}}Y$ 标成 $\hat\epsilon_Y$，$P^\perp_{X_{-j}}X_j$ 标成 $\hat\epsilon_{x_j}$。
  • 下面：If linear model is true, $\hat\epsilon_Y$ is linear in $\hat\epsilon_{x_j}$。
  • 空气质量的图上，两条轴旁边都写着 Removed W + S（去掉了 Wind 和 Solar.R）。
为什么看这张图就能检查线性

由 FWL：$P^\perp_{X_{-j}}Y = P^\perp_{X_{-j}}X_j\,\beta_j + P^\perp_{X_{-j}}\epsilon$，即 $\hat\epsilon_Y = \beta_j\,\hat\epsilon_{x_j} + (\text{噪声})$。如果模型对 $x_j$ 的形式是对的，这张图就是一条过原点、斜率为 $\beta_j$ 的直线加上随机散点。如果点排成曲线，说明「$x_j$ 线性进入模型」这一点不对。普通的「$y$ 对 $x_j$」散点图做不到这一点，因为它混进了其他变量的作用。

ozone_residuals <- lm(Ozone ~ Wind + Solar.R, data = air)$residuals   # y with W, S removed
temp_residuals  <- lm(Temp  ~ Wind + Solar.R, data = air)$residuals   # x_j with W, S removed
lm(ozone_residuals ~ temp_residuals)
# (Intercept)  temp_residuals
#   3.583e-15       1.652e+00      # slope = Temp coefficient in the full model
截距 3.583e-15

两份残差的均值都是 0（$X_{-j}$ 里有截距列），所以这条回归线必过原点，截距理论上等于 0。输出的 $3.6\times10^{-15}$ 只是计算机的舍入误差。

3异方差与三明治方差

课件第 7 页：Heteroskedasticity + 手写空白页

📝 课件原文

通常假设 $\mathrm{Var}(\epsilon) = \sigma^2I$，但假如 $\mathrm{Var}(\epsilon) = \sigma^2V$。后果：

  • $E(\hat\beta) = \beta$，不变。
  • $\mathrm{Var}(\hat\beta) = \sigma^2(X^TX)^{-1}(X^TVX)(X^TX)^{-1} \ne \sigma^2(X^TX)^{-1}$。
  • $E(\hat\sigma^2) \ne \sigma^2$。

相关是严重的违背，可能让假设检验失效。需要对相关建模，或者用稳健的方法。

✍️ 手写
  • $\sigma^2I$ 圈起来：indep & equal var residuals（残差独立、方差相等）；$V$ 旁边：arbitrary（任意的）。
  • $E(\hat\beta) = \beta$ 下面画线；$X^TVX$ 里的 $V$ 下面打了记号。
  • 下面的推导： $$\mathrm{Var}(\hat\beta\mid X) = \mathrm{Var}\big(\underbrace{(X^TX)^{-1}X^T}_{\text{const.}}\,Y\mid X\big) = \underbrace{(X^TX)^{-1}X^T}_{B}\ \underbrace{\mathrm{Var}(Y\mid X)}_{\text{Meat}}\ \underbrace{X(X^TX)^{-1}}_{B}$$ 旁边写着 "Sandwich Estimator"，箭头指向中间的 Meat：all the magic happens here!
一步步看
  1. 给定 $X$ 时，$(X^TX)^{-1}X^T$ 是一个常数矩阵 $A$，所以 $\hat\beta = AY$ 是 $Y$ 的线性变换。
  2. 线性变换的方差：$\mathrm{Var}(AY) = A\,\mathrm{Var}(Y)\,A^T$（L02 §9）。$A^T = X(X^TX)^{-1}$，两片「面包」一样。
  3. 只有中间的「肉」$\mathrm{Var}(Y\mid X)$ 用到了假设：假设 1 + 2 成立时它是 $\sigma^2I$，三明治化简成 $\sigma^2(X^TX)^{-1}$；不成立时化简就是错的，R 的 summary() 默认给的标准误也就错了。
  4. $E(\hat\sigma^2) \ne \sigma^2$：$E[RSS] = \sigma^2\,\mathrm{tr}\big((I - H)V\big)$，只有 $V = I$ 时才等于 $\sigma^2(n - p)$。
✍️ 手写空白页：If $V$ is known, then start by decorrelating $$\mathrm{Var}(Y\mid X) = \sigma^2V = LL^T\ \ \text{(Cholesky)}$$ $$L^{-1/2}Y = L^{-1/2}X\beta + L^{-1/2}\epsilon,\qquad \mathrm{Var}(\epsilon) = \sigma^2V,\quad \mathrm{Var}(L^{-1/2}\epsilon) = I$$ $$\tilde Y = \tilde X\beta + \tilde\epsilon$$
注意：L 的幂次

用 Cholesky 分解 $\sigma^2V = LL^T$ 时，应当左乘 $L^{-1}$ 而不是 $L^{-1/2}$：$\mathrm{Var}(L^{-1}\epsilon) = L^{-1}LL^TL^{-T} = I$。「$-1/2$ 次方」是另一种写法：用对称平方根 $V^{1/2}$（L01 讲过的矩阵平方根）时左乘 $V^{-1/2}$。课件 GLS 那页用的是 Cholesky 版本 $S^{-1}$，老师后面「Back to classic」那页用的是 $V^{-1/2}$ 版本，两者给出同一个 $\hat\beta$（§7）。

「去相关」在做什么

如果知道误差的协方差结构 $V$，就先把数据「拉直」：找一个矩阵把 $\epsilon$ 变成独立同方差的 $\tilde\epsilon$，同样的矩阵作用在 $Y$ 和 $X$ 上。变换后的模型满足经典假设，直接用 OLS 就行。这就是 §7 的 GLS。

4残差自相关

课件第 8–14 页：Residual Autocorrelation + 手写

📝 课件原文
  • 时间序列数据里常有自相关：$\epsilon_{i+1} = \rho\epsilon_i + w_i$，$w_i \overset{iid}{\sim} N(0, \sigma^2)$。
  • 可以画残差对时间的图，或 $e_i$ 对 $e_{i-1}$ 的图；自相关图（ACF）；Durbin–Watson 检验： $$DW = \frac{\sum_{i=2}^n(e_i - e_{i-1})^2}{\sum_{i=1}^n e_i^2}$$
✍️ 手写
  • 标题旁画了一条随时间起伏的残差曲线（$\epsilon$ 对 $t$）。
  • Durbin–Watson 旁边：Testing for presence of temporal dependence（检验时间上的依赖）。
  • 公式旁边：Testing whether neighboring residuals are closer than expected（检验相邻残差是否比预期更接近）。

  • 右边：Ignoring fconvict（这个模型漏掉了女性定罪率 fconvict）；四个 *** 被涂了红。
  • 下面：$Y = \beta_1X_1 + \underbrace{\beta_2X_{fconvict} + \epsilon}_{\tilde\epsilon}$。
漏掉变量为什么会造成自相关

真实模型里有 $\beta_2X_{fconvict}$，但拟合时没放进去，它就被并进了误差：$\tilde\epsilon = \beta_2X_{fconvict} + \epsilon$。fconvict 这类社会指标逐年缓慢变化，今年高、明年多半也高，所以 $\tilde\epsilon$ 也会一连几年同号，表现为自相关。四个 *** 涂红，是在提醒：误差不独立时，这些很小的 p 值不可信。

5稳健标准误：EHW 与 cluster-robust

课件第 15–16 页：Robust Standard Errors + 两页手写

📝 课件原文

EHW（Eicker–Huber–White）假设观测之间独立，但允许异方差：

$$\widehat{\mathrm{Var}}(\hat\beta) = (X'X)^{-1}\Big(\sum_{i=1}^n x_i'\hat e_i^2x_i\Big)(X'X)^{-1}$$

✍️ 手写：$\hat e_i = y_i - \hat\beta x_i$（第 $i$ 个残差）。

✍️ 手写：What can we do about it?

Correct the variance estimates.（修正方差的估计。）

Heterosked. Robust: Assume $\mathrm{Var}(Y\mid X) = V = \mathrm{diag}(\sigma_1^2, \sigma_2^2, \dots, \sigma_n^2)$。Uncorrelated, but unequal var.

$$\mathrm{Var}(\hat\beta) = (X^TX)^{-1}(X^TVX)(X^TX)^{-1}$$

中间的 $V$ need to estimate（需要估计），用estimated residual 代替每个 $\sigma_i^2$：

$$\text{Het. Robust Standard Errors ("EHW")} = (X^TX)^{-1}\Big(\sum_{i=1}^n \hat e_i\,x_i'x_i\Big)(X^TX)^{-1}$$

$\hat e_i = y_i - x_i\hat\beta$，ith est. residual；$n \to \infty$ 时，中间那一项 $\Rightarrow E[\sigma_i^2 x_i^Tx_i]$，unbiased for the（真实的肉）。

注意：残差要平方

手写的中间项是 $\sum \hat e_i\,x_i'x_i$，漏了平方，应为 $\sum \hat e_i^2\,x_i'x_i$（课件公式里是 $\hat e_i^2$）。$\hat e_i^2$ 是 $\sigma_i^2$ 的（粗糙的）估计，$\hat e_i$ 本身平均是 0，不能当方差用。

为什么一个残差就能估计一个方差

单个 $\hat e_i^2$ 估计 $\sigma_i^2$ 非常不准，但我们不需要逐个估准，只需要中间那个 $p\times p$ 矩阵 $\sum_i \sigma_i^2 x_i'x_i$ 估准。它是 $n$ 项的和，$\hat e_i^2$ 的误差在求和时互相抵消，所以 $\frac1n\sum \hat e_i^2x_i'x_i$ 在 $n\to\infty$ 时收敛到 $E[\sigma_i^2x_i'x_i]$。这也说明 EHW 是一个大样本方法，小样本时会偏小（R 里 sandwich::vcovHC 默认的 HC3 做了小样本修正）。

✍️ 手写：What if $$\mathrm{Var}(Y\mid X) = V = \begin{pmatrix} V_1 & & 0\\ & V_2 & \\ 0 & & \ddots\ V_G\end{pmatrix}$$

G groups of correlated observations, uncorrelated between groups.（$G$ 组观测，组内相关，组间不相关。）例子：People w/in towns（同一个镇的人）、Students w/in schools（同一所学校的学生）—— nested data collection（嵌套的数据收集）。想要："Cluster Robust" Standard Errors。

📝 课件原文 + ✍️ 手写

聚类稳健标准误允许簇内相关（例如同一个人在不同时间的观测）：

$$\widehat{\mathrm{Var}}(\hat\beta) = (X'X)^{-1}\Big(\sum_{g=1}^G\Big(\sum_{i\in g}x_i'\hat e_i\Big)'\Big(\sum_{i\in g}x_i'\hat e_i\Big)\Big)(X'X)^{-1}$$

$G$ 是簇的个数，$i \in g$ 表示观测 $i$ 在簇 $g$ 里。手写：外层求和是 Sum over groups，内层是 Sum over obs. within a group；$\hat e_i = y_i - x_i\hat\beta$；圈起来的乘积是 an estimate of $\hat V_g$, the covariance within group；页面顶上标着 "Meat"。

和 EHW 的区别

EHW 的肉是 $\sum_i (x_i'\hat e_i)(x_i'\hat e_i)'$，每个观测自己和自己相乘，只估计对角线。Cluster 版本先在组内把 $x_i'\hat e_i$ 加起来，再平方，于是同一组内不同观测的交叉乘积 $x_i'\hat e_i\hat e_jx_j$ 也被算进去了，这些正是组内协方差（上面 $V_g$ 的非对角元）。每组只有一个观测时，两者完全一样。代价是：有效样本量变成了组数 $G$，组太少时它也不可靠。

library(sandwich); library(lmtest)
coeftest(fit, vcov = vcovHC(fit, type = "HC0"))                 # EHW (heteroskedasticity-robust)
coeftest(fit, vcov = vcovCL(fit, cluster = ~ school))          # cluster-robust by school

6Assumption-lean 回归

课件第 17–19 页：Assumption Lean Regression（阅读：Berk 等人的同名论文）+ 手写

✍️ 手写（第 17 页）
  • Joint distribution, $P$, over $(Y, X)$. 和通常的设定不同，把 $X$ 当成随机的（不对 $X$ 取条件）。
  • $$\beta(P) = \arg\min_{\beta\in\R^p} E_P\big[(Y - X\beta)^2\big]$$ $\beta(P)$ 标为 Estimand（估计目标），$E_P$ 是 averaging over dist. of $(Y, X)$，整个东西叫 "population OLS"（总体 OLS）。
✍️ 手写空白页

In standard setting：$\hat\beta$ is solution to $X^T(Y - X\beta) = 0$（"Normal Equation"，这里 $X$、$Y$ 是固定的矩阵）。

In Population Version：

$$E\big[X^T(Y - X\beta)\big] = 0\ \Rightarrow\ E[X^TY] = E[X^TX]\beta\ \Rightarrow\ \beta(P) = E[X^TX]^{-1}E[X^TY]$$

Exists as long as $E[X^TX]$ is invertible. No other assumptions needed.（只要 $E[X^TX]$ 可逆就存在，不需要其他假设。）

换一个角度看回归

经典设定说「真实模型就是 $Y = X\beta + \epsilon$，我们去估计 $\beta$」。Assumption-lean 的设定说：不管真实关系是什么样，总存在一条「在总体中平方误差最小的直线」，它的系数就是 $\beta(P)$；样本 OLS $\hat\beta$ 估计的就是它。这样 $\beta(P)$ 永远有定义，哪怕真实关系是弯的、方差不相等、正态不成立。代价是：$\beta(P)$ 的含义变了，它不一定是「因果效应」，也不一定是「真实曲线的斜率」，而是「最好的线性近似」的斜率。这种设定下做推断，用的正是 §5 的稳健（三明治）标准误。

✍️ 手写（第 18 页）

(nonlinear) Truth：$Y = \mu(X) + \epsilon(X)$。图上的 $x$、$y$ 旁边写 Random。Error is $\delta(x)$：

$$\delta(x) = y - \beta X = \big(y - \mu(x)\big) + \big(\mu(x) - \beta X\big) = \underbrace{\epsilon(x)}_{\text{noise}} + \underbrace{\eta(x)}_{\text{mis-spec. error}}$$

中间一步旁边写 (add & sub $\mu(x)$)。

✍️ 手写（第 19 页）
  • 左图：When $\mu(x) \ne \beta X$, $\beta(P)$ changes if I change the distribution of $X$. 老师在两段局部画了红色的切线，又用绿色画了一个更宽的 $X$ 分布和对应的直线。
  • 右图：$\beta(P)$ is invariant to dist. of $X$ iff $\mu(X) = \beta X$ (truth is linear).
这对实际有什么影响

模型误设时，同一个回归在不同人群（$X$ 的分布不同）上会得到不同的系数，而且不是因为抽样误差。比如年轻人样本和老年人样本得出的「年龄效应」不同，可能只是因为真实曲线是弯的。所以报告结果时要说清楚 $X$ 的范围，外推到别的人群要小心。

7GLS 与 WLS

手写空白页「Back to classic」+ 课件第 20–21 页

✍️ 手写：Back to classic

OLS：$\hat\beta = \arg\min\|Y - X\beta\|^2$，well motivated when $Y \sim N(X\beta, \sigma^2I)$（线性、同方差、独立）。

GLS（Different Estimator）：Assume $V^{-1/2}Y = V^{-1/2}X\beta + V^{-1/2}\epsilon$，$\mathrm{Var}(\epsilon) = V$，即 $\tilde Y = \tilde X\beta + \tilde\epsilon$，$\mathrm{Var}(\tilde\epsilon) = I$。

$$\hat\beta = (\tilde X'\tilde X)^{-1}\tilde X'\tilde Y\ \ \text{(usually OLS w/ } \tilde y, \tilde X)$$ $$= (X^TV^{-1/2}V^{-1/2}X)^{-1}X'V^{-1/2}V^{-1/2}Y\ \ \text{(sub back in)} = (X^TV^{-1}X)^{-1}X'V^{-1}Y\ \ \text{Generalized Least Squares}$$ $$\ne (X^TX)^{-1}X^TY\ \ \text{if } V \text{ isn't proportional to the identity.}$$
📝 课件原文：GLS

如果 $V$ 已知，用 $\tilde y = S^{-1}y$，$\tilde X = S^{-1}X$，$\tilde\epsilon = S^{-1}\epsilon$ 把相关的模型变成独立的模型，其中 $V = SS^\top$（$S$ 来自 Cholesky 分解）。变换后 $\tilde y = \tilde X\beta + \tilde\epsilon$，$\mathrm{Var}(\tilde\epsilon) = \sigma^2I$。GLS 估计：$\hat\beta = (X^TV^{-1}X)^{-1}X^TV^{-1}y$。

两种平方根给出同一个答案

不管用 Cholesky 的 $S$ 还是对称平方根 $V^{1/2}$，代回去时出现的都是 $(S^{-1})^TS^{-1} = (SS^T)^{-1} = V^{-1}$，或者 $V^{-1/2}V^{-1/2} = V^{-1}$。所以最终公式都是 $(X^TV^{-1}X)^{-1}X^TV^{-1}y$。由 Gauss–Markov 定理（应用在变换后的模型上），在 $V$ 已知时 GLS 是 BLUE，比 OLS 方差小。实际中 $V$ 往往不知道，要先估计它（可行 GLS），或者干脆用 OLS 加稳健标准误。

📝 课件原文：WLS
  • 观测独立但方差不等时，$V$ 是对角的，写成 $V = \mathrm{diag}(1/w_1, \dots, 1/w_n)$。
  • $$\hat\beta = \arg\min_\beta (y - X\beta)^TV^{-1}(y - X\beta) = \arg\min_\beta\sum_{i=1}^n w_i\Big(y_i - \sum_{j=1}^p\beta_jx_{ij}\Big)^2$$
  • 方差大的观测权重小。在 lm 里用 weights 选项。
✍️ 手写
  • Special case of GLS where $V$ is diagonal. 公式旁：Minimize weighted S.S. errors（最小化加权的误差平方和）。
  • 补充：observations with small residual variance get large weights（残差方差小的观测权重大）。
  • 例子：$\bar y_i \sim N(X_i\beta, \sigma^2/n_i)$，$\bar y_i$ 是 outcome for group $i$（第 $i$ 组的平均结果），$n_i$ 是 # of people in group $i$；所以 $w_i = n_i$。
为什么 $w_i = n_i$

$n_i$ 个人的平均值，方差是单人方差的 $1/n_i$。$V$ 的第 $i$ 个对角元是 $1/n_i$（差一个 $\sigma^2$），按 $V = \mathrm{diag}(1/w_i)$ 就得到 $w_i = n_i$。直觉上：100 个人的平均值比 2 个人的平均值可靠 50 倍，理应占 50 倍的分量。

9标准化残差

课件第 27 页：Standardized Residuals + 手写

📝 课件原文
  • 残差：$e = y - \hat y = (I - H)y$；残差的方差：$\mathrm{Var}(e) = \sigma^2(I - H)$。
  • 标准化残差：$$e_i' = \frac{e_i}{\hat\sigma\sqrt{1 - h_{ii}}}$$
  • 标准化残差帮助处理发现非常数方差。
✍️ 手写
  • $H = X(X'X)^{-1}X'$（proj. matrix，投影矩阵）。
  • $\mathrm{Var}(e) = \sigma^2(I - H)$ 下面：under homosked.（在同方差下）。
  • 标准化残差记作 $\tilde e_i$，旁边写 $\sim N(0, 1)$。
  • 把课件的 "address" 划掉改成 detect（发现，而不是解决）。
  • Look for $\tilde e$ that are outside $[-2, 2]$.
读这几行
  1. $\mathrm{Var}(e) = (I - H)\,\sigma^2I\,(I - H)^T = \sigma^2(I - H)$，用到了 $I - H$ 对称、幂等（L01）。这一步需要同方差。
  2. 第 $i$ 个残差的方差是 $\sigma^2(1 - h_{ii})$：每个残差的方差不一样，杠杆大的点残差方差小。
  3. 除以自己的标准差之后，每个 $\tilde e_i$ 的方差都约为 1。在正态假设下，大约 95% 应当落在 $[-2, 2]$ 内。$\sim N(0,1)$ 只是近似：$\hat\sigma$ 是估计出来的，而且各残差之间并不独立。

10删除残差（Jackknife residuals）

课件第 28–29 页：Deletion Residuals + 手写

📝 课件原文

删除残差减小单个观测（潜在离群值）对自己的影响：

$$e_i^* = \frac{y_i - \hat y_{(i)}}{\sigma\sqrt{1 + x_i^T(X_{(i)}^TX_{(i)})^{-1}x_i}}$$

删除残差帮助识别强影响点。用删除残差检查离群值：$e_i^* \sim t_{n-p-1}$。相当于同时检验了所有观测，要注意多重比较。离群值：考虑是不是录入错误，或者用稳健方法；也许 WLS 更合适？

✍️ 手写
  • $\hat y_{(i)}$ 圈起来：Fitted value when excluding observation $i$（去掉第 $i$ 个观测后的拟合值）。
  • $X_{(i)}^TX_{(i)}$ 下面：w/out $i$；两个 $x_i$ 下面画线。
  • 旁边：$\sim N(0, 1)$ if $\sigma^2$ is known；根号部分：Prediction variance（预测方差）。
  • 下面画了一张草图：一个高高的红点 $y_i$，红虚线是 fit w/ $y_i$ in（含这个点的拟合），蓝线是不含它的拟合。
  • $e_i^* \sim t_{n-p-1}$ 被圈起来。
分母为什么是这样

去掉第 $i$ 个点后，$\hat y_{(i)} = x_i^T\hat\beta_{(i)}$ 是用其他 $n - 1$ 个点对第 $i$ 个点的预测，而 $y_i$ 和这 $n - 1$ 个点独立。所以 $y_i - \hat y_{(i)}$ 的方差就是 L03 §8 的「新观测的预测方差」：$\sigma^2\big(1 + x_i^T(X_{(i)}^TX_{(i)})^{-1}x_i\big)$。根号里的 1 来自 $y_i$ 自己的噪声，后一项来自 $\hat\beta_{(i)}$ 的不确定性。

实际使用时 $\sigma$ 要换成去掉第 $i$ 个点后估计的 $\hat\sigma_{(i)}$（自由度 $n - 1 - p$），这才得到 $t_{n-p-1}$（课件公式分母写的是 $\sigma$，对应老师说的「$\sigma^2$ 已知时 $\sim N(0,1)$」）。用 $\hat\sigma_{(i)}$ 的好处是：离群值不会把自己的 $\hat\sigma$ 撑大，从而掩盖自己。

rstandard(fit)    # standardized residuals e_i'
rstudent(fit)     # deletion (studentized) residuals e_i^*
n <- nobs(fit); p <- length(coef(fit))
qt(1 - 0.05 / (2 * n), df = n - p - 1)   # Bonferroni cutoff, 3.62 for the air quality fit

11一致性、杠杆与影响

课件第 30–33 页：Consistency, Leverage, and Influence、Isolated Departure + 手写

📝 课件原文
  • 一致性：不一致的点（离群值）是残差大的点。
  • 杠杆：如果 $h_{ii}$（$H$ 的第 $i$ 个对角元）大，这个点的杠杆就大，它可能对整体拟合有很大影响。 $$\hat y_i = h_{ii}y_i + \sum_{j\ne i}h_{ij}y_j$$
  • 影响：基于删除单个观测的 Cook's distance，综合了残差和杠杆： $$D_i = \frac{\|\hat y - \hat y_{(i)}\|^2}{p\hat\sigma^2} = \frac{(\hat\beta_{(i)} - \hat\beta)^TX^TX(\hat\beta_{(i)} - \hat\beta)}{p\hat\sigma^2} = \frac1p\,(e_i')^2\,\frac{h_{ii}}{1 - h_{ii}}$$
  • 杠杆只取决于协变量，Cook's distance 还取决于响应，是更直接的度量。
读这几个公式
  • $h_{ii}$ 的含义：$\hat y = Hy$ 的第 $i$ 行。$h_{ii}$ 是「$y_i$ 对自己的拟合值有多大发言权」。$h_{ii}$ 接近 1 时，拟合线几乎被迫穿过这个点。$0 \le h_{ii} \le 1$，平均值 $p/n$（因为 $\mathrm{tr}(H) = p$）。
  • Cook's D 的三种写法：第一种是「去掉这个点后，所有拟合值一共变了多少」；第二种是「系数变了多少」，用 $X^TX$ 度量距离，正是 L03 §10 置信椭圆的形状；第三种说明只需要一次拟合就能算出来，并且清楚地显示 影响 = 残差² × 杠杆因子。
  • 常用的参考线：$D_i > 4/n$ 值得看一眼，$D_i > 1$ 很严重。
✍️ 手写（第 32 页三张图）

(a) Inconsistent, Low Leverage；(b) Consistent, High Leverage；(c) High leverage, Influential，虚线旁写 w/out ★（不含星号点的拟合）。

📝 课件原文（第 33 页）
  1. 「★」和其余数据不一致，但它的杠杆小，所以对拟合的影响小。
  2. 「★」和其余数据一致，所以对拟合影响小（尽管杠杆大）。
  3. 「★」和其余数据不一致，而且杠杆大，所以对拟合影响大。

13方差稳定变换

课件第 36–38 页：Variance Stabilizing Transforms（这周没有批注）

📝 课件原文
  • 很多应用里，用什么变换凭常识或经验就能看出来。
  • 假设响应的方差是其期望的函数，想找一个变换让变换后的方差恒定。
  • 具体地（省略下标 $i$），设 $\mathrm{Var}(y) = g^2(\mu)$，$\mu = E(y)$。要找 $f$ 使 $\mathrm{Var}(f(y))$ 为常数。

由一阶 Taylor 展开 $f(y) \approx f(\mu) + (y - \mu)f'(\mu)$，得

$$\mathrm{Var}(f(y)) \approx \mathrm{Var}(y)\big[f'(\mu)\big]^2 = g^2(\mu)\big[f'(\mu)\big]^2 = \text{const}$$ $$\Rightarrow\ f'(y) = \frac{c}{g(y)}\ \Rightarrow\ f(y) = c\int\frac{dy}{g(y)}$$
一步步看
  1. Taylor 展开里 $f(\mu)$ 是常数，$f'(\mu)$ 也是常数，所以 $f(y)$ 的随机性全来自 $(y - \mu)$，方差 $= [f'(\mu)]^2\,\mathrm{Var}(y)$。这叫 delta 方法。
  2. 要它对所有 $\mu$ 都等于常数 $c^2$，就需要 $f'(\mu) = c/g(\mu)$：方差大的地方，变换的斜率要小，把散布压回去。
  3. 积分一次就得到 $f$。
情形$g(\mu)$变换 $f(y)$例子
变异系数恒定$c\mu$$c\int\frac{dy}{y} = c\log y$收入、浓度，标准差和均值成比例
$\mathrm{Var}(y) \propto \mu$$c\sqrt\mu$$c\int\frac{dy}{\sqrt y} = c\sqrt y$（差一个常数 2）Poisson 计数
比例$c\sqrt{\mu(1-\mu)}$$c\int\frac{dy}{\sqrt{y(1-y)}} = c\arcsin\sqrt y$（差一个常数 2）命中率、通过率

14Box–Cox 变换

课件第 39–46 页：Box-Cox Transformation、Likelihood、MLE、Confidence Region for λ、Practical Notes、Air quality（这周没有批注）

📝 课件原文

设 $y > 0$，考虑变换族

$$y^{(\lambda)} = \begin{cases}\dfrac{y^\lambda - 1}{\lambda}, & \lambda \ne 0\\[4pt] \log y, & \lambda = 0\end{cases}$$

目标：希望 $E(y^{(\lambda)}) = X\beta$ 且 $\mathrm{Var}(y^{(\lambda)}) = \sigma^2I$。基于原始数据 $y$ 的似然：

$$L(\beta, \sigma^2, \lambda\mid y) = (2\pi\sigma^2)^{-n/2}\exp\Big(-\frac{1}{2\sigma^2}\|y^{(\lambda)} - X\beta\|^2\Big)\prod_{i=1}^n y_i^{\lambda - 1}$$
  1. 固定 $\lambda$，最大化似然求出 $\hat\beta$、$\hat\sigma^2$。
  2. 代回似然，得到轮廓对数似然：$$l_p(\lambda) = -\frac n2\log\Big\{\frac{RSS(\lambda, y)}{n}\Big\} + (\lambda - 1)\sum_{i=1}^n\log y_i$$

$\lambda$ 的近似 $100(1-\alpha)\%$ 置信区域：$\big\{\lambda : l_p(\hat\lambda) - l_p(\lambda) \le \tfrac12\chi^2_1(1-\alpha)\big\}$。

实用提示：把 $\hat\lambda$ 取整成更好解释的值；如果有 $y_i < 0$，给所有 $y$ 加一个常数使其为正；对离群值敏感。

公式里的几个细节
  • $\prod y_i^{\lambda-1}$ 从哪来：我们对 $y^{(\lambda)}$ 假设了正态，但似然要写成原始数据 $y$ 的密度，需要乘上变量替换的 Jacobian $\big|\frac{dy^{(\lambda)}}{dy}\big| = y^{\lambda - 1}$。没有这一项，不同 $\lambda$ 下的似然不在同一尺度上，没法比较（比如 $\lambda$ 很小时 $y^{(\lambda)}$ 的数值本身就小，RSS 会人为地变小）。
  • 轮廓似然：固定 $\lambda$ 时就是普通回归，$\hat\sigma^2 = RSS/n$，代回后 $\exp$ 那一项变成常数 $e^{-n/2}$，只剩 $-\frac n2\log(RSS/n)$ 加上 Jacobian 的对数。于是只需对一串 $\lambda$ 各跑一次回归，画出 $l_p(\lambda)$ 找最高点。
  • 置信区间：似然比检验 $2[l_p(\hat\lambda) - l_p(\lambda)] \approx \chi^2_1$，所以曲线比最高点低不超过 $\chi^2_1(0.95)/2 = 1.92$ 的 $\lambda$ 都在 95% 区间里。

15共线性

课件第 47–56 页：Collinearity、A Confidence Region for Air Quality、A simple example、Identifying strong collinearity（这周没有批注；置信椭圆的部分见 L03 §10–§11）

📝 课件原文
  • 某些协变量是其他协变量的线性组合时，$X^\top X$ 奇异，$\beta$ 没有唯一的 LS 估计。对预测不是问题！
  • 共线性指 $X^TX$ 接近奇异，会导致 $\beta$ 的估计不精确、不稳定。
  • 办法：去掉高度相关的协变量，或者用岭回归等方法。
课件的三个「Checking intuition」问题
  1. 为什么强共线性是问题？ 数据分不清两个几乎一样的变量各自的作用：$\mathrm{Var}(\hat\beta) = \sigma^2(X^TX)^{-1}$ 里 $(X^TX)^{-1}$ 的对角元很大，系数的标准误很大，换一份数据系数可能完全变样（甚至变号）。
  2. 违反了哪条假设？ 一条都没有。§1 的假设 1–3 都和 $X$ 的列之间的关系无关，$\hat\beta$ 仍然无偏，标准误也算得对（只是很大）。完全共线时违反的是「$X$ 列满秩」这一前提。
  3. 能做什么？ 去掉或合并高度相关的变量；收集能把它们分开的数据；用岭回归（用一点偏差换方差）；如果目标只是预测，可以不管它（预测值 $\hat y = Hy$ 只取决于列空间，不取决于怎么分配系数）。
📝 课件原文：识别强共线性
  • 看协变量的相关矩阵，可以发现两两之间的共线。
  • 把每个协变量对其他所有协变量回归，$R^2$ 接近 1 说明有问题；或者看方差膨胀因子 $\mathrm{VIF}_j = 1/(1 - R_j^2)$，VIF > 5 算大。
  • 条件数 $\kappa = \sqrt{\lambda_1/\lambda_p}$（$X^TX$ 最大、最小特征值之比的平方根）。

为什么「大样本时非正态不是问题，除非要预测区间」

$\hat\beta$ 是 $y$ 的线性组合，由中心极限定理，样本大时它近似正态，$t$ 检验和置信区间照样可用。预测区间不一样：它要覆盖的是单个新观测 $y_0 = x_0^T\beta + \epsilon_0$，$\epsilon_0$ 只有一个，不会被平均掉，它是什么分布，区间就得照着什么分布来画。

一句话

只要均值模型对，$\hat\beta$ 就无偏；假设出问题，坏掉的是不确定性。诊断就是用残差去检查每条假设，补救要么修正估计方法（WLS、GLS、变换），要么修正标准误（三明治）。
