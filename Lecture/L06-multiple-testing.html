Lecture 6：多重检验（Multiple Testing）

第 6 周 · 老师课件 multiple_testing.qmd 和课堂手写批注 multiple_testing_annotated_part1.pdf 逐页中文讲解

0怎么读这一页

前几讲每次只做一个检验，控制它的第一类错误在 5%。这一讲的问题是：同时做很多个检验时，「5%」还有什么意义？比如检验回归里所有的系数，或者在几千个基因里找和疾病有关的。

  1. 控制「犯任何一个错」的概率（§1–§6）：FWER、LSD、Bonferroni、Scheffé。
  2. 控制「发现里错的比例」（§7–§11）：FDR、Benjamini–Hochberg、q 值，用乳腺癌基因表达数据演示。
  3. 研究实践（§12–§13）：p-hacking、分岔路径、怎么做可重复的研究。

1单个检验的两类错误

课件第 2 页：Errors in a Single Test + 手写空白页

📝 课件原文

检验一个假设 $H_0$：

  • 第一类错误：原假设为真时拒绝了它。
  • 第二类错误：原假设为假时没有拒绝它。
不拒绝 $H_0$拒绝 $H_0$
$H_0$ 为真正确第一类错误（假阳性）
$H_0$ 为假第二类错误（假阴性）正确（功效）
✍️ 手写
  • 「single hypothesis $H_0$」旁：$\beta = 0$（例子）。
  • 第一类错误旁：Control at Pr. α (e.g. .05)；右下角「Correct」旁：(Power)。
  • 空白页：Type I: Reject when null is true. (False Pos.)；Type II: Don't reject when null is false. (False Neg.)

2多重比较与 FWER

课件第 3–6 页：Multiple Comparisons + 手写

📝 课件原文

考虑多个假设 $H_{i0}$，$i = 1, \dots, q$，例如 $H_{i0}: a_i^T\beta = c_i$。用计数记录两类错误：

# 不拒绝# 拒绝
真的 $H_{i0}$UV（假阳性个数）
假的 $H_{i0}$TS（真阳性个数）
📝 课件原文（续） $$\text{FWER} = P(V > 0)$$

令 $E_i$ = 当 $H_{i0}$ 为真时没有拒绝它。按构造，第一类错误率 $P(E_i^c) = \alpha$，于是

$$P(E_i) = 1 - \alpha,\qquad \text{FWER} = 1 - P(V = 0) = 1 - P\big(\cap_{i=1}^qE_i\big)$$

如果所有 $E_i$ 独立：$\text{FWER} = 1 - \prod_{i=1}^qP(E_i) = 1 - (1 - \alpha)^q$。

✍️ 手写
  • 「multiple hypotheses」旁：e.g. test all regression coefs；e.g. find genes associated w/ disease。
  • V 旁：# of false rejections over all tests；表旁：(counts)，表里都是个数。
  • FWER 下：$= \alpha$? Limit the probability of any mistakes.（限制犯任何一个错误的概率。）
  • $P(E_i^c) = \alpha$ 旁：$= $ e.g. 0.05；$E_i^c$ 是 falsely reject test $i$ ($H_{0i}$ is true)。
  • $P(V = 0)$ 下：No mistakes；「If all $E_i$ are independent」高亮；最后：For $q$ independent tests.
一步步读
  1. FWER（family-wise error rate，族错误率）把 $q$ 个检验看成一个「家族」，问的是整个家族里至少出现一个假阳性的概率。
  2. 「至少一个错」的反面是「一个都没错」，即所有真零假设都没被拒绝：$\{V = 0\} = \cap_i E_i$（这里 $i$ 只取真零假设）。
  3. 独立时，交集的概率等于各自概率的乘积：$(1 - \alpha)^q$。$q$ 一大，这个数迅速趋于 0，FWER 迅速趋于 1。
alpha <- 0.05
# Probability of at least 1 Type I error among q independent tests
ggplot() + stat_function(fun = \(q) 1 - (1 - alpha)^q) + xlim(c(0, 100)) +
  ylab("FWER") + xlab("Number of tests (q)") + theme_bw(base_size = 16)

3对置信区间的影响

课件第 7–9 页：Reminder: testing coefficients、Impact on confidence intervals、Reminder: F-test

📝 课件原文
  • 给定 $\sigma^2$，$a^T\hat\beta \sim N\big(a^T\beta,\ \sigma^2a^T(X^TX)^{-1}a\big)$。
  • $a^T\beta$ 的 $100(1-\alpha)\%$ 置信区间：$a^T\hat\beta \pm t_{n-p}(1 - \alpha/2)\,\hat\sigma\sqrt{a^T(X^TX)^{-1}a}$。
  • 当 $|t| \ge t_{n-p}(1-\alpha/2)$ 时在水平 α 下拒绝 $H_0: a^T\beta = c$，其中 $t = \dfrac{a^T\hat\beta - c}{\hat\sigma\{a^T(X^TX)^{-1}a\}^{1/2}}$。

记 $E_i$ 为「$a_i^T\beta$ 的 95% 置信区间盖住真值」这一事件，按构造 $P(E_i) = 1 - \alpha$。同时覆盖概率 $P(\cap_{i=1}^qE_i)$ 通常小于 $1 - \alpha$。

F 检验：$\dfrac{(A\hat\beta - c)^T[A(X^TX)^{-1}A^T]^{-1}(A\hat\beta - c)/q}{\|y - X\hat\beta\|^2/(n-p)} \sim F_{q,n-p}$。

检验和区间是一回事

「$c$ 落在 $a^T\beta$ 的 95% 置信区间里」等价于「检验 $H_0: a^T\beta = c$ 在 5% 水平下不拒绝」。所以多重检验的问题原样搬到区间上：每个区间 95% 可信，不等于所有区间一起 95% 可信。这两张复习页（L03 §6 和 L02 §19）在这里是为后面的 LSD 和 Scheffé 做准备。

4LSD：先 F 检验，再 t 检验

课件第 10 页：Least significant difference test + 手写

📝 课件原文

最小显著差（LSD）检验是一个两步程序：

  • 先做 F 检验（如 $H_0: A\beta = c$）；
  • 如果 F 检验显著，再做 $t$ 检验（如 $H_{i0}: a_i^T\beta = c_i$）。
  • F 检验对 FWER 的增长有一些保护作用，但不够！
  • 而且 $t$ 检验会失准，因为它们没有考虑到 F 检验这一步的筛选（见 McGough, 2025）。
✍️ 手写

「two-step procedure」高亮。F 检验旁：First test if any coefs different from 0.「not enough」旁：Fails w/ "partial nulls"。

「部分零假设」是什么意思

完全零假设：所有 $H_{i0}$ 都为真。这时第一步的 F 检验本身就是 5% 水平，只有 5% 的时候进入第二步，所以 FWER 不超过 5%。部分零假设：有些 $H_{i0}$ 为假（有真效应），其余为真。真效应会让 F 检验几乎每次都显著，第二步几乎总会执行，剩下那些真零假设就等于在做不校正的 $t$ 检验，FWER 又涨回去了。实际研究里几乎总是部分零假设，所以 LSD 的保护作用很有限。

5Bonferroni 校正

课件第 11 页：Bonferroni + 手写空白页

📝 课件原文

把每个比较的显著性水平从 α 降到 $\alpha/q$，由 Bonferroni 不等式，FWER 就得到了保护：

$$P\big(\cap_{i=1}^qE_i\big) = 1 - P\big(\cup_{i=1}^qE_i^c\big) \ge 1 - \sum_{i=1}^qP(E_i^c) = 1 - q\frac{\alpha}{q} = 1 - \alpha$$
✍️ 手写
  • 标题旁：Goal: Control FWER at α = 0.05，下面补了 q-tests。
  • $\alpha/q$ 旁：For each test, set Type I error to α/q.
  • 空白页画了 $t$ 统计量的分布：Normal 情形 Reject if (t-stat > $t_\alpha$)，尾部面积 α；Bonferroni: Reject if $t > t_{\alpha/q}$，门槛在更远的尾巴上，面积只有 α/q。
  • Costs me a lot of power (ability to find true pos.)
读这串不等式
  1. 第一个等号：德摩根律，「全都没错」的反面是「至少一个错」。
  2. 不等号：并集的概率不超过各自概率之和（Boole / Bonferroni 不等式），因为求和时重叠的部分被算了不止一次。这一步不需要独立，所以 Bonferroni 对任意相关结构都有效。
  3. 每个 $P(E_i^c) = \alpha/q$，加起来正好是 α。

代价：$q$ 越大，每个检验的门槛越严，真效应越难被发现。检验之间正相关时（比如相关的基因），Bonferroni 的不等号很松，会过度保守。

6Scheffé 的 S 方法

课件第 12–13 页：Scheffé's S-method + 手写

📝 课件原文

Scheffé 给出对任意线性组合 $h^\top\beta$ 都成立的 $100(1-\alpha)\%$ 同时置信区间：

  • 它把 $t$ 分布换成了 F 分布。
  • 非常保守。对所有可能的线性组合同时控制 FWER，因此允许「数据窥探」（data snooping）。
$$h^T\hat\beta \pm \sqrt{pF_{p,n-p}(1-\alpha)}\ \hat\sigma\sqrt{h^T(X^TX)^{-1}h}$$

证明：取 $A = I$、$c = \beta$，有 $\dfrac{(\hat\beta - \beta)^\top X^\top X(\hat\beta - \beta)}{p\hat\sigma^2} \sim F_{p,n-p}$。令 $b = \hat\beta - \beta$，$L = (X^\top X)^{-1}$，$m = p\hat\sigma^2F_{p,n-p}(1-\alpha)$。则：（课件到这里就停了）

✍️ 手写
  • 「replaces the t-distribution by F-distribution」高亮。
  • $\sqrt{pF_{p,n-p}(1-\alpha)}$ 记作 $K$，旁边：makes interval very large when $p$ is large；下面：Low Power。
  • $P(h'\hat\beta > K\ \forall h) = 1 - \alpha$（意思是：区间对所有 $h$ 同时成立的概率是 $1 - \alpha$）。
  • 和 $t$ 检验的联系：t-test: $Z \sim t_{n-p}$，$Z^2 \sim F_{1,n-p}$。
把证明补完
  1. 置信椭圆：以 $1 - \alpha$ 的概率，$b^T X^TX\,b \le m$，即 $b^TL^{-1}b \le m$。
  2. 对任意 $h$，用 Cauchy–Schwarz 不等式（以 $L$ 为度量）： $$(h^Tb)^2 = \big((L^{1/2}h)^T(L^{-1/2}b)\big)^2 \le (h^TLh)(b^TL^{-1}b)$$
  3. 椭圆事件成立时，$(h^Tb)^2 \le (h^TLh)\,m$，即 $$|h^T\hat\beta - h^T\beta| \le \sqrt{m\,h^TLh} = \sqrt{pF_{p,n-p}(1-\alpha)}\ \hat\sigma\sqrt{h^T(X^TX)^{-1}h}$$ 而且对所有 $h$ 同时成立。
  4. 反过来，如果对所有 $h$ 都成立，取等号成立的那个方向 $h \propto L^{-1}b$，就推出椭圆事件。所以「所有区间同时覆盖」和「椭圆覆盖」是同一个事件，概率正好是 $1 - \alpha$。

这也解释了老师的批注：$p = 1$ 时 $\sqrt{F_{1,n-p}} = t_{n-p}$（$Z^2 \sim F_{1,n-p}$），Scheffé 退化成普通 $t$ 区间；$p$ 越大，要同时保护的方向越多，倍数越大。L03 §9 的 Working–Hotelling 带就是 Scheffé 用在 $h = x_0$ 上的特例。

「允许数据窥探」

Bonferroni 要求事先定好要检验的 $q$ 个组合；如果看了数据才决定比较哪一组，就不知道 $q$ 该算多少。Scheffé 对无穷多个组合同时成立，所以看完数据再挑任何一个组合来报告，它的区间仍然有效。代价就是很宽。

7错误发现率（FDR）

课件第 14 页：Multiple Comparisons + 手写

📝 课件原文

错误发现比例（FDP）：$Q = \dfrac{V}{V + S}$。错误发现率是 FDP 的期望：

$$\text{FDR} = E[Q]$$

约定：$V + S = 0$ 时 $Q = 0$。

✍️ 手写

表的「# Reject」一列（V 和 S）被框起来，旁边：Among all rejections ("discoveries"), what fraction are "bad"?（在所有拒绝，也就是「发现」里，有多大比例是错的？）

FWER 和 FDR 的区别
  • FWER $= P(V > 0)$：只要有一个假发现就算失败。适合错一个代价就很大的场合（比如药物审批）。
  • FDR $= E\big[\frac{V}{V+S}\big]$：允许有假发现，但控制它们在所有发现里的平均比例。适合筛选：几千个基因里挑一批候选，后续实验再验证，混进 5% 的假发现可以接受。
  • 例子：报告 100 个发现，FDR = 5% 意味着平均约 5 个是假的；FWER = 5% 则要求「100 个里一个假的都没有」的概率达到 95%，门槛要严得多。
  • 约定 $V + S = 0$ 时 $Q = 0$，是为了在一个都没拒绝时避免 0/0。

为什么零假设下 p 值是均匀的

设检验统计量 $T$ 在 $H_0$ 下的累积分布函数是 $F_0$（连续），单侧 p 值 $p = F_0(T)$（老师画的是左侧面积）。对任意 $u \in [0, 1]$：

$$P(p \le u) = P\big(F_0(T) \le u\big) = P\big(T \le F_0^{-1}(u)\big) = F_0\big(F_0^{-1}(u)\big) = u$$

累积分布函数是 $u$，正是 $U(0,1)$。这也就是「在 α 水平下拒绝 = $p \le \alpha$」第一类错误恰好为 α 的原因。

9Benjamini–Hochberg 程序

课件第 15–16 页 + 手写

📝 课件原文

BH 程序简单，对独立的检验有效。记 $H_{0(1)}, \dots, H_{0(q)}$ 为 $q$ 个零假设，对应 p 值 $p_1, \dots, p_q$，$p_{(1)}, \dots, p_{(q)}$ 为从小到大排序后的 p 值。对给定的 α，找最大的 $k$ 使得

$$p_{(k)} \le \frac kq\alpha$$

把最显著的前 $k$ 个报告为「发现」。

定理：若 p 值 $p_1, \dots, p_q$ 独立，则 BH 程序控制 $E[Q] = \pi_0\alpha \le \alpha$，其中 $\pi_0$ 是真零假设所占的比例。$\pi_0$ 未知，在一些假设下可以估计。这说明原始的 BH 程序是保守的。（参见 Efron《Large Scale Inference》。）

✍️ 手写

标题上写 BH。α 旁：FDR（这里的 α 是要控制的 FDR 水平）。右上：Do q tests, sort p-values. $p_{(k)}$ 下：kth smallest p-value。定理里的 $E[Q]$ 下标 FDR。

注意：课件的下标笔误

课件写的是「$H_{0(1)}, \dots, H_{0(1)}$」，应为 $H_{0(1)}, \dots, H_{0(q)}$。

为什么门槛是 $k\alpha/q$

假如把所有 $p \le t$ 的都拒绝。零假设下 p 值均匀，$q$ 个检验里大约有 $q\pi_0 t \le qt$ 个零假设会落进去（假发现的个数）。如果一共拒绝了 $k$ 个，假发现比例大约是 $\frac{qt}{k}$。要它不超过 α，就要 $t \le k\alpha/q$。BH 就是在 $t = p_{(k)}$ 这些候选门槛里，选最大的一个满足这个条件的。把 $\pi_0$ 当成 1，所以实际 FDR 是 $\pi_0\alpha$，偏保守。

10pFDR 与 Storey 的 q 值

课件第 17–19 页（这周没有批注）

📝 课件原文
  • BH 程序控制的是 $E[Q] = E[Q\mid V + S > 0]\,\Pr(V + S > 0)$。
  • $\text{pFDR} = E[Q\mid V + S > 0]$（「至少有一个发现」条件下的 FDR）。动机来自贝叶斯视角。
  • q 值是对 p 值的一种调整：给出「拒绝所有 q 值不超过它的结果」时期望的 pFDR。
  • 基于「两组」模型：检验统计量的分布是零假设下的分布和备择假设下的分布的混合。

令 $\Gamma$ 为拒绝域，$\pi_0 = 1 - \pi_1$，$\pi_1$ 为非零假设的比例，假设本身 $H \sim \text{Bern}(\pi_1)$：

$$\text{pFDR}(\Gamma) = \Pr(H = 0\mid T \in \Gamma) = \frac{\pi_0\Pr(T \in \Gamma\mid H = 0)}{\pi_0\Pr(T \in \Gamma\mid H = 0) + \pi_1\Pr(T \in \Gamma\mid H = 1)} = \frac{\pi_0\cdot\{\text{Type I error of }\Gamma\}}{\pi_0\cdot\{\text{Type I error of }\Gamma\} + \pi_1\cdot\{\text{Power of }\Gamma\}}$$
注意：课件的小笔误

课件写的是「$pi_0 = 1 - \pi_1$」（少了反斜杠，渲染成了斜体字母 pi），应为 $\pi_0 = 1 - \pi_1$。

读这个公式
  • 这就是贝叶斯公式：已知某个检验落进了拒绝域，它其实是零假设的概率是多少？分子是「零假设并且被拒绝」，分母是「被拒绝」（零假设被拒绝 + 非零假设被拒绝）。
  • 它清楚地显示了 pFDR 取决于三样东西：零假设的比例 $\pi_0$、拒绝域的第一类错误率、拒绝域的功效。同样的 5% 门槛，如果绝大多数假设都是零假设（$\pi_0$ 接近 1）、功效又低，拒绝的结果里大部分都会是假的。
  • $\pi_0$ 可以从 p 值直方图的平坦部分估计（§8 的想法），这比 BH 直接假设 $\pi_0 = 1$ 更有功效。

混合模型（课件第 25–27 页）

课件把 p 值的分布写成 $f(p) = \pi_0\cdot 1 + (1 - \pi_0)\,\text{Beta}(p; a, b)$：零假设部分是均匀密度 1，非零部分用一个堆在 0 附近的 Beta 分布描述，用 optim 最大化似然（参数限制在合法范围内，用 L-BFGS-B）。拟合后，门槛为 $t$ 时的 FDR 估计是

$$\widehat{\text{FDR}}(t) = \frac{\pi_0\,t}{\pi_0\,t + (1 - \pi_0)\,F_{\text{Beta}}(t; a, b)}$$

这正是 §10 的 pFDR 公式：$t$ 是零假设下的第一类错误率，$F_{\text{Beta}}(t)$ 是功效。

pval_seq <- seq(0.001, 0.1, length.out = 1000)

max(pval_seq[fdrs <= 0.05])        # 0.002981982

12p-hacking 与分岔路径

课件第 30–31 页（这周没有批注）

📝 课件原文

发表出来的结果可能有很多种方式出问题：

  • 「抽屉效应」：不显著的结果被放进抽屉、不发表。
  • 多重检验：需要按检验个数校正；研究者的「自由度」。

参考：tylervigen.com/spurious-correlations（虚假相关的例子）。

Gelman 和 Loken 的「分岔路径的花园」（Garden of Forking Paths）列了四种情形：

  1. 基于唯一检验统计量 $T$ 的经典检验，作用于观测数据得 $T(y)$。
  2. 从一组可能的检验中事先选定一个：$T(y; \phi)$，$\phi$ 预先登记。例如 $\phi$ 可以是回归里控制变量的选择、变换、数据编码和剔除规则，以及关注哪个主效应或交互。
  3. 没有刻意挑选的研究者自由度：只基于数据算了一个检验，但如果数据不同，会做另一个检验：$T(y; \phi(y))$，观测到的只是 $\phi(\cdot)$ 在实际数据处的取值。
  4. 「钓鱼」：对 $j = 1, \dots, J$ 都算 $T(y; \phi_j)$，然后报告最好的结果 $T(y; \phi^{\text{best}}(y))$。

「这就是频率学派推理（有点矛盾）的本质：如果你接受 p 值的概念，就必须尊重对『换一组数据时你会怎么做』进行建模的正当性。」

第 3 种情形为什么也有问题

p 值的定义是「如果 $H_0$ 为真、重复整个研究过程，得到这么极端结果的概率」。如果分析方式取决于数据长什么样（看到某个子组差异大才去检验它），那么「重复研究过程」时，分析方式也会跟着变，真实的假阳性率就不是名义上的 5%。研究者即使只做了一个检验、没有刻意钓鱼，问题也存在。这句引文的意思就在这里。

13可重复性与可复现性

课件第 32 页：Reproducibility and replicability

📝 课件原文：建议
  • 有明确的假设，事先定好分析计划。
  • 使用样本拆分：在一半数据上探索，在另一半上确认和检验。
  • 对自己做了什么保持透明。
  • 报告稳健性 / 敏感性分析。
  • 公开数据和代码。
样本拆分为什么有效

在探索用的一半上，可以随意尝试、挑选（分岔路径随便走）；选定之后，在另一半没看过的数据上只做一次检验。第二半数据和挑选过程独立，所以这次检验的 p 值是诚实的。代价是用来检验的样本只有一半，功效降低。
