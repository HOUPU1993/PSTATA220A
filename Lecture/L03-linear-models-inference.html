1空气质量数据与整体 F 检验

课件第 42–48 页：Example: Air Quality Data、GGPairs + 手写

数据

1973 年 5–9 月纽约每天的测量，154 天，6 个变量；去掉缺失值后剩 111 天。老师在变量说明那页把 Temp（日最高气温，°F）圈了出来，后面几页都围绕它。

  • Ozone：臭氧浓度（ppb），罗斯福岛 13–15 点的平均值，这是响应变量；
  • Solar.R：太阳辐射（Langley），中央公园 8–12 点；
  • Wind：平均风速（mph），拉瓜迪亚机场；
  • Temp：日最高气温（°F）；Month、Day：月和日。
fit_null <- lm(Ozone ~ 1, data = air)                        # intercept only
fit_full <- lm(Ozone ~ Wind + Solar.R + Temp, data = air)    # all covariates
anova(fit_null, fit_full)
#   Res.Df    RSS Df Sum of Sq      F    Pr(>F)
# 1    110 121802
# 2    107  48003  3     73799 54.834 < 2.2e-16 ***
print((121802 - 48003)/3/(48003/107))   # 54.83333
✍️ 本周手写
  • lm(Ozone ~ 1) 旁边：intercept only（只有截距）。
  • Wind + Solar.R + Temp 下面：all covariates（全部协变量）。
  • 手算那行写成 $\dfrac{(RSS_{H_0} - RSS_{full})/3}{RSS_{full}/107}$，其中 3 是 "Difference in # of params"（两个模型参数个数之差，4 − 1）。
  • 结果 54.83 圈起来：F-stat，$F_{3,107}$。
把公式和表对上
  • Res.Df：两个模型的残差自由度 $n - p$。零模型 $111 - 1 = 110$，完整模型 $111 - 4 = 107$。
  • Df = 3：两者之差，也就是约束的个数 $q$（L02 §19 的公式）。
  • Sum of Sq = 73,799：额外平方和 $RSS_{H_0} - RSS_{full}$。零模型的 RSS 就是 $SS_{total}$，所以这个数也是完整模型的 $SS_{model}$。
  • $F = \frac{73799/3}{48003/107} = \frac{24600}{448.6} = 54.83$，与 summary(fit_full) 最后一行的 F-statistic 一样，$R^2 = 1 - 48003/121802 = 0.606$。

2偏 R²（Partial R²）

课件第 49–50 页：Partial Coefficient of Determination + 手写

📝 课件原文

偏 $R^2$ 描述：在已经剔除（partialing out）其他协变量之后，某个协变量还能解释结果剩余方差的多少。

$$R^2_{Y\sim Z\mid X} = \frac{RSS_X - RSS_{Z,X}}{RSS_X}$$
✍️ 本周手写
  • $X$：reference covariates（参照的协变量，已经在模型里的）；$Z$："additional"（新加进来的那个）。
  • $RSS_X$ 圈起来：S.S. w/out Z（不含 $Z$ 时的残差平方和）；$RSS_{Z,X}$ 圈起来：w/ Z（含 $Z$ 时的）。
  • 最下面一行：$$R^2_{Y\sim Z\mid X} \approx \frac{\mathrm{Var}(Y\mid X) - \mathrm{Var}(Y\mid X, Z)}{\mathrm{Var}(Y\mid X)}$$
那个「≈」是怎么来的

$RSS_X / n$ 是「只知道 $X$ 时，$Y$ 还剩多少波动」的估计，也就是 $\mathrm{Var}(Y\mid X)$；$RSS_{Z,X}/n$ 估计的是 $\mathrm{Var}(Y\mid X, Z)$。分子分母同除以 $n$，公式就变成：知道 $Z$ 之后，剩余方差减少了百分之几。普通 $R^2$ 是同一个思路，只是参照对象换成「什么都不知道」：$R^2 \approx \frac{\mathrm{Var}(Y) - \mathrm{Var}(Y\mid X)}{\mathrm{Var}(Y)}$。

library(sensemakr)
partial_r2(fit_full)          # plug in the lm object
# (Intercept)    Wind     Solar.R    Temp
#  0.0679       0.1952   0.0586     0.2841

fit_no_temp <- lm(Ozone ~ Wind + Solar.R, data = air)   # Ozone with Wind, Solar.R removed
temp_fit    <- lm(Temp  ~ Wind + Solar.R, data = air)   # Temp  with Wind, Solar.R removed
cor(fit_no_temp$residuals, temp_fit$residuals)^2        # 0.2841039

cov(fit_no_temp$residuals, air$Temp)                    # 104.8254
cov(fit_no_temp$residuals, temp_fit$residuals)          # 104.8254 (same)
✍️ 本周手写

partial_r2 旁边：Plug lm object（直接把 lm 的结果传进去）。Wind 那个数标成 $R^2_{Y\sim W\mid T,S}$，Temp 那个标成 $R^2_{Y\sim T\mid W,S}$：竖线右边是「已经控制了的」变量。

三种算法，同一个数（以 Temp 为例）
  1. 用 RSS（课件公式）：不含 Temp 时 RSS = 67,053，含 Temp 时 48,003，$(67053 - 48003)/67053 = 0.284$。
  2. 用残差的相关（课件代码）：Ozone 去掉 Wind、Solar.R 后的残差，和 Temp 去掉 Wind、Solar.R 后的残差，相关系数的平方 = 0.284。这就是 §5 的 FWL 图里的那个相关。
  3. 用 $t$ 值（顺便一提，课件没写）：$R^2_{Y\sim Z\mid X} = \frac{t^2}{t^2 + (n-p)}$，Temp 的 $t = 6.516$，$\frac{42.46}{42.46 + 107} = 0.284$。
最后两行协方差为什么相等

$\text{Temp} = (\text{Temp 能被 Wind、Solar.R 解释的部分}) + (\text{Temp 的残差})$。前一部分在 (1, Wind, Solar.R) 的列空间里，而 Ozone 的残差和这个列空间垂直（正规方程），协方差为 0。所以 Ozone 残差和 Temp 的协方差，等于它和 Temp 残差的协方差。这件事是 §5 FWL 定理的关键。

3顺序平方和检验（Sequential SS tests）

手写空白页 + 课件第 51–52 页：Partial R-squared and Sequential SS

✍️ 本周手写（一整页）

Sequential S.S. tests：Measure reduction in error by adding a variable given the factors already included ("sequential")。

即：在已经放进去的变量的基础上，再加一个变量，误差减少了多少（所以叫「顺序」）。老师写的统计量：

$$F_{1,\,n-p} = \frac{RSS_{k-1} - RSS_k}{RSS_{full}}$$
注意：分母少写了 n − p

分母应该是完整模型的 $\hat\sigma^2 = RSS_{full}/(n-p)$，不是 $RSS_{full}$ 本身。下一页课件的代码就是这么算的：(45694) / ((48003)/107)。完整写法：

$$F = \frac{(RSS_{k-1} - RSS_k)/1}{RSS_{full}/(n-p)} \sim F_{1,\,n-p}$$

分子除以 1，是因为每一步只多一个参数。

anova(fit_full)              # lm(Ozone ~ Wind + Solar.R + Temp): this order
#            Df Sum Sq Mean Sq F value    Pr(>F)
# Wind        1  45694   45694 101.854 < 2.2e-16 ***
# Solar.R     1   9055    9055  20.184 1.786e-05 ***
# Temp        1  19050   19050  42.463 2.424e-09 ***
# Residuals 107  48003     449
(45694) / ((48003)/107)      # 101.8532
(9055)  / ((48003)/107)      # 20.18384
(19050) / ((48003)/107)      # 42.46297
✍️ 本周手写：每一行在检验什么
  • 三行编号 1、2、3：变量按公式里的顺序依次进入。
  • Wind 行：Test: Intercept only vs including Wind。比较「只有截距」和「截距 + Wind」。
  • Solar.R 行：$H_0$: Wind ≠ 0，others = 0；vs：Wind & Solar ≠ 0。即原假设模型里已经有 Wind，只检验再加 Solar.R 有没有用。
  • Temp 行（黄色高亮）：同理，比较 (Wind, Solar.R) 和 (Wind, Solar.R, Temp)。
anova(lm(Ozone ~ Temp + Wind + Solar.R, data = air))   # order is different!
#            Df Sum Sq Mean Sq  F value    Pr(>F)
# Temp        1  59434   59434 132.4816 < 2.2e-16 ***
# Wind        1  11378   11378  25.3630 1.937e-06 ***
# Solar.R     1   2986    2986   6.6563   0.01124 *
# Residuals 107  48003     449
✍️ 本周手写

公式那里圈出来写着：order is different!（顺序不同了！）Temp 那一行被高亮：同一个变量，排第一时 SS = 59,434，排最后时只有 19,050。

为什么顺序会改变结果

Wind 和 Temp 相关（−0.50），它们能解释的 Ozone 变异有一部分是重叠的。谁先进模型，重叠的那部分就算谁的。如果变量之间完全不相关（正交），重叠为 0，顺序就无所谓了（§13 的 ToothGrowth 就是这样）。所以 Type I 平方和回答的是一个依赖顺序的问题：「在前面这些变量的基础上，它还能多解释多少」。

4Type III 平方和

课件第 53–54 页：Type III sum of squares + 手写

📝 课件原文

检验某个因子（主效应或交互项）的效应时，先控制模型里所有其他效应，包括其他主效应和所有包含这个因子的高阶交互项。

✍️ 本周手写
  • 表的旁边：car::Anova( … , type = "III")（car 包的大写 A 的 Anova，不是基础 R 的 anova）。
  • 第二张表（变量换了顺序）旁边：Change order, same result.
library(car)
Anova(fit_full, type = "III")
#             Sum Sq  Df F value    Pr(>F)
# (Intercept)   3494   1  7.7888  0.006227 **
# Wind         11642   1 25.9495 1.516e-06 ***
# Solar.R       2986   1  6.6563  0.011237 *
# Temp         19050   1 42.4630 2.424e-09 ***
# Residuals    48003 107
Type III = 「每个变量都最后加入」

Type III 的 SS 就是「把这个变量从完整模型里拿掉，RSS 增加多少」。这正是 §2 偏 $R^2$ 的分子，也是 §6 单个系数 $t$ 检验所检验的东西。所以：

  • 每个 Type III 的 $F$ = summary() 里对应 $t$ 值的平方：Temp $6.516^2 = 42.46$ ✓，Wind $(-5.094)^2 = 25.95$ ✓，Solar.R $2.580^2 = 6.66$ ✓。
  • 偏 $R^2$ = Type III SS ÷ (Type III SS + $RSS_{full}$)：Temp $\frac{19050}{19050 + 48003} = 0.284$ ✓。
  • 表里还有一行 (Intercept)：也检验了截距是否为 0（3,494，$F = 7.79$）。这个检验问的是「所有变量都为 0 时 Ozone 的均值是不是 0」，一般没什么实际意义。

5Frisch–Waugh–Lovell（FWL）定理

课件第 55–56 页 + 两页手写推导

📝 课件原文

把 $X$ 分成两组 $X_1$、$X_2$，假设 $Y = X_1\beta_1 + X_2\beta_2 + \epsilon$。那么 $\beta_2$ 可以通过下面的回归得到：

$$P^\perp_{X_1}Y = P^\perp_{X_1}X_2\,\beta_2 + \epsilon_2,\qquad P^\perp_{X_1} = I - X_1(X_1^TX_1)^{-1}X_1^T$$

$P^\perp_{X_1}$ 把向量投影到与 $X_1$ 列空间垂直的子空间上。

✍️ 本周手写（第 55 页）
  • 标题旁：(FWL)；$P^\perp$ 那行旁边：($X_1$ annihilated by $P^\perp_{X_1}$)，即 $X_1$ 被 $P^\perp_{X_1}$「消灭」了。
  • Two Regressions（两次回归）：
    ① $Y \sim X_1$，取残差，记作 $Y^{\perp X_1}$；
    ② $X_2 \sim X_1$，取残差，记作 $X_2^{\perp X_1}$。
✍️ 本周手写（推导页）

两边同时左乘 $P^\perp_{X_1}$：

$$\underbrace{P^\perp_{X_1}Y}_{\tilde Y} = \cancel{P^\perp_{X_1}X_1\beta_1} + \underbrace{P^\perp_{X_1}X_2}_{\tilde X_2}\,\beta_2 + \underbrace{P^\perp_{X_1}\epsilon}_{\tilde\epsilon}$$

红笔标注：$P^\perp_{X_1}Y$ 是 Residuals of lm(Y ~ X₁)，$P^\perp_{X_1}X_2$ 是 Residuals of lm(X₂ ~ X₁)。中间那项被划掉，剩下

$$\tilde Y = \tilde X_2\beta_2 + \tilde\epsilon$$

接着的问题：lm(Y ~ X₁ + X₂) 给出的 $\hat\beta_2$，什么时候和 lm(Y ~ X₂) 一样？ 答：$X_1 \perp X_2$ 时，因为这时 $P^\perp_{X_1}X_2 = X_2$。

一步步看推导
  1. 为什么 $P^\perp_{X_1}X_1 = 0$：$X_1$ 的每一列本来就在 $X_1$ 的列空间里，投到「与这个空间垂直的方向」上什么也不剩。代数上：$(I - H_1)X_1 = X_1 - X_1(X_1^TX_1)^{-1}X_1^TX_1 = X_1 - X_1 = 0$。这就是「annihilated」。
  2. 剩下的方程是一个普通回归：响应是 $\tilde Y$，设计矩阵是 $\tilde X_2$，系数还是同一个 $\beta_2$。用最小二乘：$\hat\beta_2 = (\tilde X_2^T\tilde X_2)^{-1}\tilde X_2^T\tilde Y$。
  3. 它和完整回归的 $\hat\beta_2$ 一样：这是定理的内容（课件代码在真实数据上验证：两个都是 1.652093）。直观上，完整回归在估 $\beta_2$ 时，只能用 $X_2$ 里不能被 $X_1$ 表示的那部分信息，因为能被 $X_1$ 表示的部分，分不清该算给 $\beta_1$ 还是 $\beta_2$。
  4. 什么时候不用控制 $X_1$：如果 $X_2 \perp X_1$，$X_2$ 里没有任何能被 $X_1$ 表示的部分，$\tilde X_2 = X_2$。再加上 $X_2^T P^\perp_{X_1} = (P^\perp_{X_1}X_2)^T = X_2^T$，所以 $\hat\beta_2 = (X_2^TX_2)^{-1}X_2^T Y$，正是只用 $X_2$ 回归的结果。（实际数据里 $X_1$ 通常含截距，「正交」相当于「中心化后不相关」。）
注意：手写的小笔误

第二页推导最后写的是 $P^\perp_{X_1}X_2 = X$，应为 $= X_2$（前一页同一个式子写的就是 $X_2$）。

X_ws   <- cbind(rep(1, nrow(air)), air$Wind, air$Solar.R) %>% as.matrix   # X_1 (from fit_full)
Pperp  <- diag(nrow(air)) - X_ws %*% solve(t(X_ws) %*% X_ws) %*% t(X_ws)   # P_perp = I - P_ws
P_Y    <- Pperp %*% air$Ozone      # residual of Ozone
P_Temp <- Pperp %*% air$Temp       # residual of Temp

c(coef(fit_full)["Temp"], coef(lm(P_Y ~ P_Temp - 1)))   # 1.652093 1.652093
summary(lm(P_Y ~ P_Temp - 1))$r.squared                 # 0.2841039
✍️ 本周手写（第 56 页）
  • 第 1 行的 X_ws 指回 fit_full：$X_1$ 就是完整模型里除 Temp 之外的列（截距、Wind、Solar.R）。
  • 第 2 行：$P^\perp_{ws} = (I - P_{ws})$。
  • 两个 1.652093 旁边：two stage（两阶段）。即 $\mathrm{lm}(P^\perp_{ws}Y \sim P^\perp_{ws}T)$。
  • r.squared 旁边：$R^2_{Y\sim T\mid W,S}$。两份残差回归的 $R^2$ 就是 §2 的偏 $R^2$。
代码里的 - 1

P_Y ~ P_Temp - 1 表示不要截距（上周 L02 讲哑变量时见过）。两份残差的均值都已经是 0（$X_1$ 里有截距列），所以截距本来就是 0，去掉它让模型和公式 $\tilde Y = \tilde X_2\beta_2 + \tilde\epsilon$ 完全一致。

6线性组合的推断：从 z 统计量到 t 统计量

课件第 57–59 页：Inference for Linear Combinations、t-Statistics and Confidence Intervals + 两页手写

📝 课件原文
  • 令 $A^T = (a_1,\dots,a_q)$，$c^T = (c_1,\dots,c_q)$。假设 $A\beta = c$ 可以拆成 $q$ 个假设：$a_i^T\beta = c_i$，$i = 1,\dots,q$。
  • 如果 $F$ 检验显著，下一个问题是为什么拒绝了 $H_0: A\beta = c$，也就是哪几个 $a_i^T\beta = c_i$ 可能不成立。
✍️ 本周手写：推导

Under Normality（在正态假设下）：

$$\hat\beta_p \sim N_p\big(\beta,\ \sigma^2(X^TX)^{-1}\big)$$

$H_0: l'\beta = \text{const}$（例如 $= 0$），$l$ 是任意固定的向量。则

$$l'\hat\beta \sim N\big(l'\beta,\ \sigma^2 l'(X'X)^{-1}l\big)$$ $$\text{Test:}\quad l'\hat\beta - l'\beta \sim N\big(0,\ \sigma^2 l'(X'X)^{-1}l\big),\qquad \frac{l'\hat\beta - l'\beta}{\sqrt{\sigma^2 l'(X'X)^{-1}l}} \sim N(0, 1)\ \ \text{(z-stat)}$$

$\sigma^2$ 被圈出来：need to estimate in practice（实际中要估计）。Replace $\sigma^2$ w/ $\hat\sigma^2 \sim \frac{\sigma^2}{n-p}\chi^2_{n-p}$：

$$\frac{l'\hat\beta - l'\beta}{\sqrt{\hat\sigma^2 l'(X'X)^{-1}l}} \sim t_{n-p}$$

Confidence Interval: $\ l'\hat\beta \pm t_{n-p,\,1-\alpha/2}\sqrt{\hat\sigma^2 l'(X'X)^{-1}l}$；$\alpha = 5\%$ $\Rightarrow$ 95% CI。

每一步用到的事实
  1. $l'\hat\beta$ 的分布：正态向量的线性组合还是正态。均值 $l'E[\hat\beta] = l'\beta$；方差用 $\mathrm{Var}(l'\hat\beta) = l'\,\mathrm{Var}(\hat\beta)\,l$（L02 §9 的 $\mathrm{Var}(Ay) = A\,\mathrm{Var}(y)A^T$，这里 $A = l'$）。
  2. 标准化：减去均值、除以标准差，得到 $N(0,1)$。但 $\sigma^2$ 不知道，所以这个 $z$ 算不出来。
  3. 换成 $\hat\sigma^2$：分子 $\sim N(0,1)$，分母 $\sqrt{\hat\sigma^2/\sigma^2} = \sqrt{\chi^2_{n-p}/(n-p)}$，而且两者独立（Cochran 定理，L02 §17）。这正是 $t$ 分布的定义 $Z/\sqrt{V/k}$。
  4. 置信区间：$P(|t| \le t_{n-p,1-\alpha/2}) = 1 - \alpha$，把不等式里的 $l'\beta$ 解出来，就是那个 $\pm$ 的区间。
$l$ 可以取什么
  • $l = (0, 1, 0, 0)^T$：只取出 Wind 的系数，就是 summary() 里那一行的 $t$ 检验（§7）。
  • $l = (0, 1, 0, -1)^T$：检验 Wind 和 Temp 的系数是否相等（这里单位不同，没有实际意义，只是示意）。
  • $l = x_0$（一组新的协变量值）：估计 $x_0$ 处的平均响应（§8）。

8预测：拟合值的分布 vs 新观测的分布

两页手写 + 课件第 62–64 页：Predictions

✍️ 本周手写：Prediction

$\hat y_0 = x_0\hat\beta$，$x_0$ is a "new" obs.（一个新的观测点，这里 $x_0$ 写成行向量）。"Fitted value"：

$$\hat\beta \sim N\big(\beta,\ \sigma^2(X'X)^{-1}\big)\ \Rightarrow\ \hat y_0 = x_0\hat\beta \sim N\big(x_0\beta,\ \sigma^2 x_0(X'X)^{-1}x_0'\big)$$

⇒ Can construct the t-stat as before（像 §6 一样构造 $t$ 统计量）。这是 distribution of the fitted value at a new obs. $x_0$（新点上拟合值的分布）。

Different From：What is the distribution of $\tilde y_0 = \hat y_0 + \epsilon$，$\epsilon \sim N(0, \sigma^2)$？

$$\mathrm{Var}(\tilde y_0) = \mathrm{Var}(\hat y_0) + \mathrm{Var}(\epsilon) = \underbrace{\sigma^2 x_0'(X'X)^{-1}x_0}_{\mathrm{Var}\ \hat y:\ \text{"goes to 0 as } n\to\infty\text{"}} + \underbrace{\sigma^2}_{\mathrm{Var}(\epsilon):\ \text{"always } \sigma^2\text{"}}$$
注意：两处手写笔误
  • $\hat y_0$ 的方差手写成了 $\sigma^2 x_0(X'X)x_0'$，漏了逆，应为 $\sigma^2 x_0(X'X)^{-1}x_0'$（上一行 $\hat\beta$ 的方差里有逆）。
  • $\mathrm{Var}(\tilde y_0)$ 的第一项写成了 $\sigma\,x_0'(X'X)^{-1}x_0$，应为 $\sigma^2$。
两个问题的区别
  • $\hat y_0$：「气温 90°F 的那些天，平均臭氧是多少？」不确定性只来自 $\hat\beta$ 估得不准。数据越多越准，方差趋于 0。
  • $\tilde y_0$：「明天（气温 90°F）的臭氧会是多少？」除了 $\hat\beta$ 的不确定性，明天自己还有随机误差 $\epsilon$。这一部分再多数据也消不掉。
  • 两项可以直接相加，因为新观测的误差 $\epsilon$ 和用来估计 $\hat\beta$ 的旧数据独立。
📝 课件原文（第 62 页）

选好模型后，对新的协变量 $x_0$，自然的预测是 $\hat y_0 = x_0^T\hat\beta$。

$$\textit{mean response}\ \text{的 CI：}\quad \hat y_0 \pm t_{n-p}(1-\alpha/2)\,\hat\sigma\sqrt{x_0^T(X^TX)^{-1}x_0}$$ $$\textit{future response}\ \text{的区间：}\quad \hat y_0 \pm t_{n-p}(1-\alpha/2)\,\hat\sigma\sqrt{1 + x_0^T(X^TX)^{-1}x_0}$$

✍️ 老师把 "mean response" 和 "future response" 涂了红，把根号里的 1 圈出来，旁边写 Bigger。

confidence_bands <- predict(reptile_lm, interval = "confidence")   # CI for the mean response
prediction_bands <- predict(reptile_lm, interval = "prediction")   # interval for a new observation
✍️ 本周手写（第 64 页的图）
  • 红色虚线（宽的那条）：Prediction Interval which covers irreducible uncertainty（覆盖了不可约的不确定性，即 $\epsilon$）。
  • 蓝色窄带：CI for $\hat y$ (regression line at any $x_0$)（回归线本身在每个 $x_0$ 处的置信区间）。
为什么蓝带中间窄、两头宽

简单回归时 $x_0^T(X^TX)^{-1}x_0 = \frac1n + \frac{(x_0 - \bar x)^2}{\sum(x_i - \bar x)^2}$。$x_0 = \bar x$ 时只剩 $1/n$；离 $\bar x$ 越远，斜率估计的误差被放大得越多。可以想成回归线绕着 $(\bar x, \bar y)$ 这个点「晃动」，离支点越远晃得越厉害。

9逐点 vs 同时置信

课件第 65 页：Pointwise vs simultaneous

📝 课件原文

每个置信区间各自以 $1 - \alpha$ 的概率覆盖对应的真值 $x_0^T\beta$。把它们连起来，就是 $100(1-\alpha)\%$ 的逐点置信带（上一页的图）。

一组置信区间的同时覆盖概率，是所有区间同时都覆盖各自真值的概率（要求严格得多）。

直观理解

逐点带上，每个位置都有 5% 的机会没盖住；看很多位置时，「至少有一处没盖住」的概率就大于 5%。要让整条真实回归线以 95% 的概率完全落在带子里，带子必须更宽。Working–Hotelling 带的做法是把 $t$ 分位数（1.98）换成 $\sqrt{p\,F_{p,n-p}(1-\alpha)} = \sqrt{2F_{2,109}} \approx 2.48$。这个数来自 §10 的置信区域：整个 $\beta$ 落在置信椭圆里，等价于所有 $x_0^T\beta$ 同时落在各自的带里。

10置信区域（Confidence Region）

课件第 66–68 页：Confidence Region、A Confidence Region for Air Quality + 手写

📝 课件原文

令 $A = I$、$c = \beta$，有

$$\frac{(\hat\beta - \beta)^TX^TX(\hat\beta - \beta)}{p\,\hat\sigma^2} \sim F_{p,\,n-p}$$

$\beta$ 的 $100(1-\alpha)\%$ 置信区域是所有满足 $(\hat\beta - \beta)^TX^TX(\hat\beta - \beta) \le p\,\hat\sigma^2F_{p,n-p}(1-\alpha)$ 的 $\beta$。$p = 2$ 时可以画成置信椭圆。置信区域考虑了系数估计值之间的相关性。

✍️ 本周手写
  • $(\hat\beta - \beta)$ 圈出来：$\sim N_p(0, \dots)$。
  • 整个分子标 $\chi^2$；分母里的 $\hat\sigma^2$ 也标 $\chi^2$，旁边写 scaling it to variance 1（把方差缩放成 1）。
  • $F_{p,n-p}$ 下面画了一个 $F$ 分布：左边大部分面积标 $1 - \alpha$，右尾标 $\alpha$，分界点就是 $F_{p,n-p}(1-\alpha)$。
把批注连成推导
  1. $\hat\beta - \beta \sim N_p\big(0, \sigma^2(X^TX)^{-1}\big)$。
  2. 令 $Z = \frac{1}{\sigma}(X^TX)^{1/2}(\hat\beta - \beta)$，则 $\mathrm{Var}(Z) = \frac{1}{\sigma^2}(X^TX)^{1/2}\sigma^2(X^TX)^{-1}(X^TX)^{1/2} = I$，即 $Z \sim N_p(0, I)$。这就是「缩放成方差 1」。
  3. 分子除以 $\sigma^2$：$\frac{(\hat\beta - \beta)^TX^TX(\hat\beta - \beta)}{\sigma^2} = Z^TZ = \sum_{j=1}^p Z_j^2 \sim \chi^2_p$。
  4. 分母：$\frac{\hat\sigma^2}{\sigma^2} \sim \frac{\chi^2_{n-p}}{n-p}$，并且和 $\hat\beta$ 独立。
  5. 相除，$\sigma^2$ 抵消：$\frac{\chi^2_p/p}{\chi^2_{n-p}/(n-p)} \sim F_{p,n-p}$。分母里的 $p$ 就是 $F$ 定义里「分子除以自由度」的那个 $p$。

只看其中两个系数（比如 Wind 和 Temp）时，把 $X^TX$ 换成这两个系数协方差矩阵的逆（$\frac{1}{\hat\sigma^2}$ 乘上 $(X^TX)^{-1}$ 对应 2×2 子块的逆），$p$ 换成 2，就是课件里 confidenceEllipse 画的东西。

为什么是椭圆

不等式左边是 L01 §2 讲的「换了一把尺子的距离」：用 $X^TX$ 当尺子量 $\beta$ 离 $\hat\beta$ 有多远（本质上是 Mahalanobis 距离，因为 $\mathrm{Var}(\hat\beta) \propto (X^TX)^{-1}$）。到中心「距离相等」的点组成椭圆，主轴方向由 $X^TX$ 的特征向量决定（L01 §10）。

11多重共线性：一个简单例子

课件第 69–70 页：A simple example（这周没有手写批注）

x1 <- rnorm(100)
y  <- 0.5*x1 + rnorm(100)
x2 <- x1 + rnorm(100, sd = 0.1)   # x2 is almost a copy of x1
lm_fit <- lm(y ~ x1 + x2)
summary(lm_fit)
#             Estimate Std. Error t value Pr(>|t|)
# (Intercept)  0.10140    0.09352   1.084    0.281
# x1           1.47816    0.98034   1.508    0.135
# x2          -0.71572    0.98693  -0.725    0.470
# Multiple R-squared: 0.465,  F-statistic: 42.15 on 2 and 97 DF,  p-value: 6.713e-14

矛盾的输出

两个系数各自都不显著（p = 0.135、0.470），但整体 $F$ 检验极显著（p = $6.7\times10^{-14}$）。原因是 $x_1$ 和 $x_2$ 几乎一模一样，数据能确定「$x_1$ 和 $x_2$ 合起来有效果」，但分不清是哪一个。

用这周的工具看：由 FWL（§5），$\hat\beta_2$ 只用 $x_2$ 里与 $x_1$ 无关的部分 $\tilde x_2$，而它只剩一点点噪声（sd = 0.1），所以 $\tilde X_2^T\tilde X_2$ 很小、标准误很大（0.98，只放 $x_1$ 时约 0.1）。由 §10，两个估计值高度负相关，置信椭圆极其细长。

12ANOVA 与平方和的类型

课件第 71–75 页：ANOVA、One-way vs Multi-way ANOVA、Types of Sum of Squares、Sequential Sum of Squares（这周没有手写批注）

📝 课件原文

用线性模型分析设计实验（因子）时，就叫方差分析（ANOVA）。它可以看成协变量都是类别变量的回归，用 $F$ 检验判断各组均值是否相等。

单因素 ANOVA：一个因子，多个水平。多因素 ANOVA：两个或以上因子，可能有交互。多因素时，平方和依因子进入模型的顺序不同，有不同的类型。

类型名称顺序有关吗衡量什么
Type I顺序 Sequential有关在已有因子基础上，加入这个因子后误差减少多少（§3）
Type II分层 Hierarchical无关控制所有其他主效应后这个因子的效应，忽略交互项
Type III偏 Partial无关控制模型里所有其他项后这个效应，主效应或交互（§4）
顺序平方和的公式

记 $SS(x_1)$、$SS(x_1,x_2)$、$SS(x_1,x_2,x_3)$ 为三个嵌套模型的解释平方和：

$$SS_{x_1} = SS(x_1),\quad SS_{x_2\mid x_1} = SS(x_1,x_2) - SS(x_1) = SS_{error}(x_1) - SS_{error}(x_1,x_2)$$ $$SS_{x_3\mid x_1,x_2} = SS(x_1,x_2,x_3) - SS(x_1,x_2) = SS_{error}(x_1,x_2) - SS_{error}(x_1,x_2,x_3)$$ $$SS_{total} = SS_{x_1} + SS_{x_2\mid x_1} + SS_{x_3\mid x_1,x_2} + SS_{error}(x_1,x_2,x_3)$$

即把 $SS_{model}$ 拆成三份：$x_1$ 单独解释的；在 $x_1$ 基础上 $x_2$ 额外解释的；再加入 $x_3$ 额外解释的。拟合三个模型就能算出来，Type I 一次性给出全部（R 的 anova() 默认就是这个）。§3 的阶梯图就是这个公式：每一级台阶是一项。

「这是一个正交设计」是什么意思

每个「剂量 × 方式」组合正好 10 只豚鼠（平衡设计），所以代表 dose 和 supp 的列（中心化后）互相正交。按 §5 FWL 的结论，正交时控制不控制其他因子，结果都一样；各因子解释的部分互不重叠，Type I 和 Type II 平方和相同，顺序也无所谓（Type III 要用正交的 sum-to-zero 编码 contr.sum 才和它们一致；R 默认的 treatment 编码下，有交互项时 Type III 的主效应会不同）。空气质量数据不是这样：Wind、Temp 相关，所以 §3 里顺序会改变结果。
