1线性模型做什么、为什么用它

课件：Linear Models（两页）+ 手写

📝 课件原文

$y$：响应变量（因变量）；$x_1, \dots, x_p$：协变量（自变量）。我们想要：① 研究 $y$ 如何依赖于 $x_1,\dots,x_p$；② 用 $x_1,\dots,x_p$ 预测 $y$。

手写：「依赖」应理解为 "is associated with"（与之相关），不一定是因果。

为什么用线性模型（老师课上写的）
  • 可解释：每个系数都有明确含义，「$x_j$ 增加 1，$y$ 平均变化 $\beta_j$」。
  • 现实中的趋势常常近似线性：是一个有用的近似，能抓住总体趋势；数学上就是泰勒展开的一阶项（见下图）。
  • 简单：参数少，不容易过拟合；容易解释，也容易学。
  • 是更复杂方法的基础：GLM、混合模型、样条、岭回归等都建立在它上面。

2条件期望与误差 ε

课件：Conditional Expectation + 手写

📝 课件原文 $$E(Y\mid X_1 = x_1, \dots, X_p = x_p) = f(x_1, \dots, x_p)$$

令 $\epsilon = Y - f(X_1,\dots,X_p)$，总可以写成回归模型 $Y = f(X_1,\dots,X_p) + \epsilon$，其中 $E(\epsilon) = 0$。

为什么会有 ε（老师课上写的）
  • 测量误差：仪器、记录都不完美。
  • 没测到的 $x$：影响 $Y$ 的因素很多，模型里只放了一部分，其余的都混进了 $\epsilon$。

老师还提到两个概念：不可约误差（irreducible error），即 $\epsilon$ 本身，再好的模型也消除不了；可约误差（reducible error），即模型 $g$ 和真实 $f$ 之间的差距，可以靠更好的模型减小。下一节会把这两者用公式分开。

3条件期望是最好的预测

课件：Conditional Expectation in Regression + 手写证明

📝 课件原文

预测误差 $R(g) = E\big(Y - g(X_1,\dots,X_p)\big)^2$，期望对 $X$ 和 $Y$ 的联合分布取。结论：条件期望 $f$ 使预测误差最小，即对所有 $g$ 都有 $R(f) \le R(g)$。

老师的证明，一步一步

① 加零（AZMO：add zero, multiply one）。在 $Y - g(x)$ 里减一个 $f(x)$ 再加一个 $f(x)$，值不变：

$$E\big[(Y - g(x))^2\big] = E\Big[\big((Y - f(x)) + (f(x) - g(x))\big)^2\Big]$$

② 展开平方 $(a + b)^2 = a^2 + b^2 + 2ab$：

$$= \underbrace{E\big[(Y - f(x))^2\big]}_{\text{方差}} + \underbrace{E\big[(f(x) - g(x))^2\big]}_{\text{Bias}^2} + 2\,\underbrace{E\big[(Y - f(x))(f(x) - g(x))\big]}_{=\,0}$$

③ 交叉项为什么是 0。给定 $x$ 时，$f(x) - g(x)$ 是固定的数，可以提出来；剩下 $E[Y - f(x)\mid x] = E[\epsilon\mid x] = 0$。

④ 结论。MSE = Variance + Bias²。第一项和 $g$ 无关；第二项 $\ge 0$，只有 $g(x) = E[Y\mid x] = f(x)$ 时才等于 0。所以条件期望使平方预测误差最小。

⑤ 线性模型的位置。老师接着写：线性模型就是假设 $E[Y\mid X]$ 是 $X$ 的线性函数。

5「线性」指的是什么

课件：The Linear Model (LM)（两页）+ 手写

📝 课件原文

收集 $n$ 个观测 $(y_i, x_{i1}, \dots, x_{ip})$，假设 $y_i = \sum_{j=1}^p \beta_j x_{ij} + \epsilon_i$，$\epsilon_i$ 是均值为 0 的随机误差。即 $f(x_1, \dots, x_p) = \sum_j \beta_j x_j$。

「线性」指模型对未知参数是线性的，而不是对自变量。

模型是 LM 吗理由
$y = \beta_1 + \beta_2x_1 + \beta_3x_1^2 + \beta_4x_1x_2 + \epsilon$✓$x_1^2$、$x_1x_2$ 只是新的列，每个 $\beta$ 都只是被乘了一个已知的数
$y = \beta_1 + \beta_2\sin(x_1) + \beta_3\log x_2 + \epsilon$✓同理，$\sin(x_1)$ 和 $\log x_2$ 都是已知的列
$y = \beta_1 + \beta_2x^{\beta_3} + \epsilon$✗$\beta_3$ 在指数上，对参数不是线性的
$y = \log(\beta_1 + \beta_2x + \epsilon)$✓老师的手写：两边取指数得 $e^y = \beta_1 + \beta_2x + \epsilon$，把 $e^y$ 当响应变量就是 LM（老师把课件里的 $x^{\beta_3}$ 改成了 $x$）

6矩阵形式、最小二乘与正规方程

课件：Matrix Form、LS Estimation + 手写推导

📝 课件原文

把 $y$、各列 $x_j$、$\epsilon$、$\beta$ 写成向量，$X = (x_1,\dots,x_p)$ 是 $n\times p$ 矩阵，则 $y = X\beta + \epsilon$。用最小二乘估计：

$$\sum_{i=1}^n\Big(y_i - \sum_{j=1}^p\beta_jx_{ij}\Big)^2 = \|y - X\beta\|^2$$

对 $\beta$ 求导并令其为 0，得正规方程 $X^TX\beta = X^Ty$。若 $X$ 列满秩，$\hat\beta = (X^TX)^{-1}X^Ty$。

老师的手写推导，一步一步

① 维数：$y_{n\times1} = X_{n\times p}\,\beta_{p\times1} + \epsilon_{n\times1}$。

② 目标：$\hat\beta = \arg\min_\beta \|y - X\beta\|_2^2$，即「平方 L2 范数」，也就是 $\epsilon$ 的平方和。

③ 展开（用 Lecture 1 的内积）：

$$\langle y - X\beta,\ y - X\beta\rangle = (y - X\beta)'(y - X\beta) = y'y + \beta'X'X\beta - 2\beta'X'y$$

④ 求导（老师说查 Matrix Cookbook）：$y'y$ 和 $\beta$ 无关，导数为 0；$\beta'X'X\beta$ 的导数是 $2X'X\beta$；$2\beta'X'y$ 的导数是 $2X'y$。令导数为 0：

$$2X'X\beta - 2X'y = 0 \iff X'(y - X\beta) = 0 \quad\text{（正规方程）}$$

⑤ 几何含义（老师写的）：残差 $y - X\hat\beta$ 和 $X$ 的每一列都垂直，残差不能再用 $X$ 的列的线性组合表示，能用 $X$ 解释的部分都已经被拿走了。

⑥ 解出：两边左乘 $(X'X)^{-1}$ 得 $\hat\beta = (X'X)^{-1}X'y$。前提是 $X'X$ 必须可逆，而当 $p < n$ 且 $X$ 列满秩时，它就是可逆的。

7拟合值与帽子矩阵 H

课件：Fitted Values and Hat Matrix、Geometry of Least Squares + 手写

📝 课件原文 $$\hat y = X\hat\beta = X(X^TX)^{-1}X^Ty = Hy,\qquad H = X(X^TX)^{-1}X^T$$

$H$ 叫帽子矩阵（也叫投影矩阵、影响矩阵）：它给 $y$「戴上帽子」变成 $\hat y$。

性质（老师课上写的，和 L01 §9 一一对应）
  • $H^2 = H$（幂等）：投两次和投一次一样。
  • $H' = H$（对称）。
  • $H$ 是一个 $n\times n$、秩为 $p$ 的矩阵。
  • 有 $p$ 个特征值等于 1，$n - p$ 个等于 0；谱分解 $H = U\Lambda U'$，$\Lambda$ 对角线上是 $p$ 个 1 和 $n-p$ 个 0（L01 §10）。
  • $I - H$ 也是投影矩阵，秩为 $n - p$。

8残差、RSS 与 σ² 的估计

课件：Residuals, RSS and estimate of σ² + 手写

📝 课件原文

残差 $e_i = y_i - \hat y_i$，$\mathbf e = \mathbf y - \hat{\mathbf y} = (I - H)\mathbf y$。

$$RSS = \sum_{i=1}^n e_i^2 = \|\mathbf e\|^2 = \mathbf y^T(I - H)\mathbf y$$

$\sigma^2$ 的无偏估计：$\hat\sigma^2 = RSS/(n - p)$（老师补充：前提是同方差）。

为什么 $\|(I-H)y\|^2 = y^T(I-H)y$（老师写的） $$\|(I-H)y\|^2 = y'(I-H)'(I-H)y = y'(I-H)(I-H)y = y'(I-H)y$$

用了两次 L01 的性质：对称（$(I-H)' = I-H$）和幂等（$(I-H)^2 = I-H$）。

9β̂ 的均值与方差（三明治公式）

课件：Properties of the LS Estimates + 手写推导

📝 课件原文

LS 估计是无偏的：$E(\hat\beta\mid X) = \beta$。在同方差下，方差为 $\mathrm{Var}(\hat\beta\mid X) = \sigma^2(X^TX)^{-1}$。

无偏性（老师的推导）

假设线性成立，$Y = X\beta + \epsilon$，所以 $E[Y\mid X] = X\beta$。给定 $X$ 时，$(X'X)^{-1}X'$ 是固定的矩阵，可以提到期望外面：

$$E[\hat\beta\mid X] = (X'X)^{-1}X'\,E[Y\mid X] = \underbrace{(X'X)^{-1}X'X}_{=I}\beta = \beta$$
方差：三明治（老师的推导）

提醒：对已知矩阵 $A$，$\mathrm{Var}(Ay) = A\,\mathrm{Var}(y)\,A'$。取 $A = (X'X)^{-1}X'$：

$$\mathrm{Var}(\hat\beta\mid X) = \underbrace{(X'X)^{-1}X'}_{\text{面包}}\ \underbrace{\mathrm{Var}(y\mid X)}_{\text{肉}}\ \underbrace{X(X'X)^{-1}}_{\text{面包}}$$

这叫三明治方差估计。老师特别强调：中间的「肉」才是假设真正起作用的地方。

假设独立且同方差（homoskedasticity，$\epsilon$ iid、方差 $\sigma^2$），则 $\mathrm{Var}(y\mid X) = \sigma^2 I$（对角线全是 $\sigma^2$，其余为 0）。代进去，中间的 $X'X$ 和一个 $(X'X)^{-1}$ 抵消：

$$\mathrm{Var}(\hat\beta\mid X) = (X'X)^{-1}X'(\sigma^2 I)X(X'X)^{-1} = \sigma^2(X'X)^{-1}\quad(p\times p)$$

10Gauss–Markov 定理（BLUE）

课件：BLUE (Gauss-Markov Theorem) + 手写

📝 课件原文

如果误差不相关且方差相等，那么对任意 $p$ 维向量 $c$，$c^T\hat\beta$ 是 $c^T\beta$ 唯一的最佳线性无偏估计（BLUE）：在所有线性无偏估计中方差最小（等价地，均方误差 $E(c^T\hat\beta - c^T\beta)^2$ 最小）。

老师写：$\arg\min\mathrm{Var}(\tilde\beta)$ subject to $E[\tilde\beta\mid X] = \beta$ $\iff$ 就是 OLS。

逐个词拆开
  • Linear：估计量是 $y$ 的线性组合，$\tilde\beta = Cy$。
  • Unbiased：平均来说等于真值。
  • Best：满足上面两条的所有估计量里，方差最小。

注意定理不需要正态，只需要「不相关 + 同方差」。如果有偏的估计量也允许，就可能找到均方误差更小的（比如以后会讲的岭回归）。

11R 里的 lm

课件：lm in R + 手写

lm(formula, data, subset, weights, na.action,
   method = "qr", model = TRUE, x = FALSE, y = FALSE, qr = TRUE,
   singular.ok = TRUE, contrasts = NULL, offset, ...)
老师圈出的三个参数
  • formula：模型公式，如 log_brain ~ log_body + class。
  • data：数据框。
  • weights：权重。给了权重就变成加权最小二乘（WLS）：最小化 $\sum w_i(y_i - x_i^T\beta)^2$。异方差时可以给方差大的点较小的权重。

12案例：脑重与体重

课件：Example: Brain and body mass（四页）→ Regression for Reptiles and Birds (Interaction) + 手写

问题与模型

脑的大小怎么随体型变化？数据：爬行动物 192 个个体（79 种），鸟类 10,176 个个体（1,903 种）。生物学上常用异速生长（allometric scaling）模型（老师批注：Haller's rule）：

$$\text{brain} \approx a\cdot\text{body}^b \quad\Longrightarrow\quad \log(\text{brain}) = \log(a) + b\log(\text{body})$$

取对数后对参数是线性的（§5），斜率 $b$ 就是「体重翻倍，脑重变成 $2^b$ 倍」。

老师的批注：classReptile 去哪了？

log_body + class 的设计矩阵每行是 $(1,\ \text{log\_body},\ \text{classBird})$，classBird 是 0/1 指示变量：

所以（老师写的）：

  • 鸟：$E[\cdots] = (-4.11 + 2.20) + 0.55\,\log\text{body}$

没有 classReptile 这一列，是因为它被吸收进了截距：截距本身就是爬行动物的截距，classBird 是「鸟比爬行动物高多少」。如果再放一列 classReptile，就有 classReptile + classBird = 截距列，$X$ 不满秩，$X^TX$ 不可逆。

去掉截距：- 1（老师的批注）

但对于只有连续变量的模型就不一样了：lm(brain ~ body) ≠ lm(brain ~ -1 + body)，后者强制直线过原点，是一个更受限的模型。

13平方和分解

课件：Decomposition of Sum of Squares（两页）+ 手写

📝 课件原文 + 老师的推导

$\mathbf 1 = (1,\dots,1)^T$，$\bar y = \sum y_i/n$。老师先写：

$$(y - \bar y\mathbf 1) = (y - \hat y) + (\hat y - \bar y\mathbf 1)$$ $$\|y - \bar y\mathbf1\|^2 = \|y - \hat y\|^2 + \|\hat y - \bar y\mathbf1\|^2$$

即 总平方和 $SS_{total}$ = 残差平方和 $RSS$（$SS_{error}$）+ 模型平方和 $SS_{model}$。

第二行为什么成立

平方展开会多一个交叉项 $2(y - \hat y)'(\hat y - \bar y\mathbf1)$。残差 $y - \hat y$ 和 $X$ 的所有列垂直；模型里有截距时，$\hat y$ 和 $\bar y\mathbf1$ 都在 $X$ 的列空间里，它们的差也在。所以交叉项为 0，就是勾股定理。（模型没有截距时，这个分解一般不成立。）

$SS_{total}$ 是 $y$ 减去均值后的平方和，减均值用掉 1 个自由度，剩 $n - 1$。模型有 $p$ 个参数，其中截距已经算在「减均值」里了，所以模型占 $p - 1$。残差剩 $n - p$。三者 $(p - 1) + (n - p) = n - 1$，和平方和一样能加起来。

15R² 与调整后的 R²

课件：Coefficient of Determination（两页）、Adjusted R²、Comparison + 手写

📝 课件原文 $$R^2 = \frac{SS_{model}}{SS_{total}} = 1 - \frac{SS_{error}}{SS_{total}}$$

$R^2$ 是响应变量的变异中被模型解释的比例；它也等于 $y$ 和 $\hat y$ 样本相关系数的平方（老师写：$\mathrm{Cor}(y, \hat y)^2$）。

老师在第二次课上补充：$R^2 = 1 - \dfrac{\hat\sigma^2}{\widehat{\mathrm{Var}}(Y)}$，其中这里的 $\hat\sigma^2 = \sum(y_i - \hat\beta x_i)^2/n$ 是残差方差的有偏估计（除以 $n$）。

cor(reptile_lm$fitted.values, reptiles_sp$log_brain)^2   # 0.9205739
summary(reptile_lm)$r.squared                             # 0.9205739  (identical)
调整后的 $R^2$ $$\bar R^2 = 1 - \frac{SS_{error}/(n - p)}{SS_{total}/(n - 1)}$$

老师的批注：分子 $\frac{RSS}{n-p} = \hat\sigma^2$ 是残差方差的无偏估计，分母 $\frac{SST}{n-1}$ 是 $\mathrm{Var}(Y)$ 的无偏估计。普通 $R^2$ 用的是两者除以 $n$ 的有偏版本。

验算爬行动物模型：$1 - \frac{14.779/77}{186.073/78} = 1 - \frac{0.1919}{2.3856} = 0.9195$ ✓。

两者比较（课件）
  • 加入一个变量，$R^2$ 一定增加（至少不减），$\bar R^2$ 可增可减。
  • $\bar R^2$ 只有在新变量的改进超过「纯靠运气」能带来的程度时才增加。
  • $\bar R^2$ 可以是负的，而且总是 $\le R^2$。

16正态假设与重要分布

课件：MLE under Gaussianity、Important Distributions + 手写（多页）

📝 课件原文
  • 最小二乘只是一个计算程序，不需要任何假设。
  • 经典推断（置信区间、假设检验）需要随机误差服从正态分布。

老师写：若 $Y = X\beta + \epsilon$，$\epsilon \sim N(0, \sigma^2 I)$，最大似然估计仍然是 $\hat\beta = (X^TX)^{-1}X^Ty$。如果 $\epsilon$ 服从别的分布，MLE 就会不同。

为什么正态下 MLE = 最小二乘（补充）

正态的对数似然是 $-\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\|y - X\beta\|^2$。对 $\beta$ 来说，最大化它就是最小化 $\|y - X\beta\|^2$。

三个重要分布（老师写的）

设 $Z_i \overset{iid}{\sim} N(0,1)$（$\mu + \sigma Z_i \sim N(\mu, \sigma^2)$）。

  • 卡方：$V = \sum_{i=1}^k Z_i^2 \sim \chi^2_k$，「自由度为 $k$ 的卡方分布」，$E[V] = k$。若 $Z_i$ 的方差是 $\sigma^2$，则 $\sum(\sigma Z_i)^2 \sim \sigma^2\chi^2_k$。
  • $t$：$Z$ 与 $V \sim \chi^2_k$ 独立，则 $T = \dfrac{Z}{\sqrt{V/k}} \sim t_k$。
  • $F$：$V_1 \sim \chi^2_{d_1}$ 与 $V_2 \sim \chi^2_{d_2}$ 独立，则 $\dfrac{V_1/d_1}{V_2/d_2} \sim F(d_1, d_2)$。
  • 两者的关系：$T^2 = \dfrac{Z^2/1}{V/k} \sim F_{1,k}$，所以只检验一个系数时 $F = t^2$。
  • $t_1$ = Cauchy：$Z_1/Z_2 \sim$ Cauchy，尾巴极厚。
注意：第一页手写的小问题

老师第一次写的是 $Z_i \sim N(0, \sigma^2)$，同时写 $E[V] = k$。两者要同时成立需要 $\sigma = 1$。后面一页老师改写成了 $Z_i \sim N(0, 1)$，并把一般情况写成 $\sum(\sigma Z_i)^2 \sim \sigma^2\chi^2_k$，以那一页为准。

17β̂、σ̂² 的分布与 t 统计量

课件：Important results + 手写（LM Theory 等多页）

📝 课件原文：重要结论
  • $\epsilon_i \overset{iid}{\sim} N(0, \sigma^2)$ 时，LS 估计 $\hat\beta$ 也是 MLE。
  • $\sigma^2$ 的 MLE 是 $\hat\sigma^2_{MLE} = RSS/n$，它是有偏的（§8 的模拟）。
  • $\hat\beta \sim N(\beta, \sigma^2(X^TX)^{-1})$。
  • $\hat\beta$ 和 $\hat\sigma^2$ 独立，且 $RSS/\sigma^2 \sim \chi^2_{n-p}$。
  • $(\hat\beta - \beta)^TX^TX(\hat\beta - \beta)/\sigma^2 \sim \chi^2_p$。
老师的推导，一步一步

① $\hat\beta$ 的分布。$\hat\beta = (X^TX)^{-1}X^T y$ 里，$(X^TX)^{-1}X^T$ 是固定已知的，只有 $y$ 是随机的。正态向量的线性变换还是正态的，均值和方差就是 §9 算的：

$$\hat\beta \sim N_p\big(\beta,\ \sigma^2(X^TX)^{-1}\big),\qquad \hat\beta_i \sim N\big(\beta_i,\ \sigma^2(X^TX)^{-1}_{ii}\big)$$

② 标准化。$\dfrac{\hat\beta_i - \beta_i}{\sqrt{\sigma^2(X^TX)^{-1}_{ii}}} \sim N(0, 1)$，这就是 z 值。问题是 $\sigma^2$ 实际中不知道。

③ 用估计值代替。$\hat\sigma^2 = \dfrac{(y - X\hat\beta)'(y - X\hat\beta)}{n - p} = \dfrac{RSS}{n-p}$，是 $\sigma^2$ 的无偏估计，$E[\hat\sigma^2] = \sigma^2$。它的分布是

$$\hat\sigma^2 \sim \frac{\sigma^2}{n-p}\,\chi^2_{n-p}$$

④ 一个（有点）令人惊讶的结果：$\hat\beta$ 和 $\hat\sigma^2$ 独立，原因是 Cochran 定理。直观上，$\hat\beta$ 只依赖 $Hy$，$\hat\sigma^2$ 只依赖 $(I-H)y$，两者在互相垂直的子空间里，正态下垂直就意味着独立。

⑤ 得到 $t$。分子 $\sim N(0, \sigma^2(X^TX)^{-1}_{ii})$，分母里的 $\hat\sigma^2(X^TX)^{-1}_{ii} \sim \frac{\sigma^2}{n-p}(X^TX)^{-1}_{ii}\chi^2_{n-p}$，两者独立。比一比，$\sigma^2$ 和 $(X^TX)^{-1}_{ii}$ 都约掉了，正好是 §16 的 $Z/\sqrt{V/k}$：

$$\frac{\hat\beta_i - \beta_i}{\sqrt{\hat\sigma^2(X^TX)^{-1}_{ii}}} \sim t_{n-p}$$

⑥ 整个向量。$(\hat\beta - \beta)^TX^TX(\hat\beta - \beta)/\sigma^2 \sim \chi^2_p$（它是 $p$ 个独立标准正态的平方和，用的是 L01 §11 的矩阵平方根把 $\hat\beta$ 标准化）。把 $\sigma^2$ 换成 $\hat\sigma^2$，两个独立的 $\chi^2$ 各除以自由度相比，就得到

$$\frac{(\hat\beta - \beta)^TX^TX(\hat\beta - \beta)/p}{\hat\sigma^2} \sim F_{p,\,n-p}$$
注意：手写里的笔误

老师第一页写的是 $\hat\sigma^2 \sim \sigma^2\chi^2_{n-p}$，少了除以 $n-p$；后面「What is the distribution of $\hat\sigma^2$」那一页改成了 $\frac{\sigma^2}{n-p}\chi^2_{n-p}$，和课件的 $RSS/\sigma^2 \sim \chi^2_{n-p}$ 一致。另外，最后那个 $F$ 统计量手写成了分母 $\hat\sigma^2/(n-p)$，按课件 §30 的公式，分母应该是 $\hat\sigma^2$ 本身（$\hat\sigma^2$ 已经除过 $n-p$ 了）。

18假设检验的哲学

课件：Philosophy of Hypothesis Testing

📝 课件原文
  • 大多数问题里，原假设几乎不可能完全成立（效应恰好是 0）。
  • 只要数据够多，通常总能检测到某个效应（为什么？）。
  • 观点：不拒绝，意味着我们的数据还不足以让认识发生有意义的改变，效应可能就在原假设附近。
回答「为什么」

标准误大约按 $1/\sqrt n$ 缩小（$\mathrm{Var}(\hat\beta) = \sigma^2(X^TX)^{-1}$，$X^TX$ 随 $n$ 线性增长）。真实效应只要不是正好为 0，$t = \hat\beta/SE$ 就会随 $\sqrt n$ 变大，p 值趋向 0。所以要同时看效应大小和置信区间，而不只看 p 值。

19额外平方和原理与 F 检验

课件：Extra sum of squares principle、F-test statistic + 手写

📝 课件原文

一般的原假设 $H_0: A\beta = c$，$A$ 是已知的 $q\times p$ 矩阵，$c$ 是 $q$ 维向量。则

$$RSS_{H_0} = RSS + (A\hat\beta - c)^T\big[A(X^TX)^{-1}A^T\big]^{-1}(A\hat\beta - c)$$

$RSS_{H_0}$ 是在原假设下（受约束的模型）的残差平方和，$RSS$ 是完整模型的。

$$F = \frac{(RSS_{H_0} - RSS)/q}{RSS/(n - p)} \overset{H_0}{\sim} F_{q,\,n-p}$$
F 的每一部分（老师的批注）
  • $RSS_{H_0} - RSS$：给 $\beta$ 加约束而多出来的平方和（额外平方和）。约束模型更受限，RSS 只会更大。
  • $q$：约束的个数。
  • $RSS/(n-p)$：不加约束的完整模型的 RSS，即 $\hat\sigma^2$。
  • 分子和分母独立，原因还是 Cochran 定理，所以比值是 $F$ 分布。

做法：分别拟合完整模型和 $H_0$ 下的简化模型，算 RSS 增加了多少，再用完整模型的 $\hat\sigma^2$ 和对应的自由度去缩放。

老师举的例子：A = I，c = 0

$H_0: \beta = 0$（所有系数都为 0），一共 $q = p$ 个约束，「检验有没有任何非零系数」。这时 $RSS_{H_0} = y^Ty$（什么都不拟合），老师写：

$$F = \frac{\big(y^Ty - y^T(I - H)y\big)/p}{y^T(I-H)y/(n-p)} = \frac{y^THy/p}{y^T(I-H)y/(n-p)} \sim F_{p,\,n-p}$$

分子 $y^THy$ 是 $y$ 在列空间上投影的长度平方，分母是在垂直方向上的；两者在垂直的子空间里，所以独立。

23偏 R²（Partial R²）

课件：Partial Coefficient of Determination（两页）

📝 课件原文

偏 $R^2$ 描述：在已经控制了其他协变量之后，某个协变量还能解释结果剩余方差的多少。

$$R^2_{Y\sim Z\mid X} = \frac{RSS_X - RSS_{Z,X}}{RSS_X}$$
读公式

$RSS_X$：只用 $X$ 时剩下的「没解释掉的」；$RSS_{Z,X}$：再加入 $Z$ 后剩下的。分子是加入 $Z$ 后新解释掉的部分，除以原来剩下的，就是 $Z$ 解释了剩余部分的百分之多少。普通 $R^2$ 的分母是全部变异，偏 $R^2$ 的分母只是控制 $X$ 后剩下的那部分。

25Frisch–Waugh–Lovell（FWL）定理

课件：Frisch–Waugh–Lovell theorem（两页）

📝 课件原文

把 $X$ 分成两组 $X_1$、$X_2$，$Y = X_1\beta_1 + X_2\beta_2 + \epsilon$。那么 $\beta_2$ 可以通过下面的回归得到：

$$P^\perp_{X_1}Y = P^\perp_{X_1}X_2\,\beta_2 + \epsilon_2,\qquad P^\perp_{X_1} = I - X_1(X_1^TX_1)^{-1}X_1^T$$

$P^\perp_{X_1}$ 把向量投影到与 $X_1$ 列空间垂直的子空间上。

三步
  1. 用 $X_1$ 回归 $Y$，取残差：$P^\perp_{X_1}Y$（Ozone 里与 Wind、Solar.R 无关的部分）。
  2. 用 $X_1$ 回归 $X_2$，取残差：$P^\perp_{X_1}X_2$（Temp 里与 Wind、Solar.R 无关的部分）。
  3. 两份残差做回归（不需要截距，残差均值已经是 0），斜率就是完整模型里的 $\hat\beta_2$。

这就是「控制其他变量」的精确含义：多元回归里某个系数，只用到了这个变量里和其他变量不相关的那部分信息。§23 的图就是第 3 步。

X_ws   <- cbind(rep(1, nrow(air)), air$Wind, air$Solar.R) %>% as.matrix   # X_1
Pperp  <- diag(nrow(air)) - X_ws %*% solve(t(X_ws) %*% X_ws) %*% t(X_ws)   # I - H_1
P_Y    <- Pperp %*% air$Ozone      # residual of Ozone
P_Temp <- Pperp %*% air$Temp       # residual of Temp
c(coef(fit_full)["Temp"], coef(lm(P_Y ~ P_Temp - 1)))   # 1.652093 1.652093
summary(lm(P_Y ~ P_Temp - 1))$r.squared                 # 0.2841: partial R^2 again

26线性组合的推断：t 统计量与置信区间

课件：Inference for Linear Combinations（两页）、t-Statistics and Confidence Intervals

📝 课件原文

$A\beta = c$ 可以拆成 $q$ 个假设 $a_i^T\beta = c_i$。如果 $F$ 检验显著，下一个问题是为什么被拒绝：哪几个 $a_i^T\beta = c_i$ 不成立？

对已知向量 $l$，$l^T\beta$ 的 LS 估计是 $l^T\hat\beta$，$\mathrm{Var}(l^T\hat\beta) = \sigma^2 l^T(X^TX)^{-1}l$，估计为 $\hat\sigma^2 l^T(X^TX)^{-1}l$。

$$t = \frac{l^T\hat\beta - c}{\sqrt{\hat\sigma^2\, l^T(X^TX)^{-1}l}} \sim t_{n-p},\qquad l^T\hat\beta \pm t_{n-p,\,1-\alpha/2}\sqrt{\hat\sigma^2\, l^T(X^TX)^{-1}l}$$
$l$ 是什么
  • $l = (0, 1, 0, 0)^T$：只取出 Wind 的系数，就是 summary() 里那一行的 $t$ 检验。
  • $l = (0, 1, 0, -1)^T$：检验 Wind 和 Temp 的系数是否相等。
  • $l = x_0$（一组新的协变量值）：估计该处的平均响应（§28）。
验算：Wind 的 95% 置信区间

28预测：均值的置信区间 vs 新观测的预测区间

课件：Predictions（三页）

📝 课件原文

新的协变量 $x_0$，预测值 $\hat y_0 = x_0^T\hat\beta$。

$$\text{平均响应的 CI：}\quad \hat y_0 \pm t_{n-p}(1-\alpha/2)\,\hat\sigma\sqrt{x_0^T(X^TX)^{-1}x_0}$$ $$\text{未来单个响应的区间：}\quad \hat y_0 \pm t_{n-p}(1-\alpha/2)\,\hat\sigma\sqrt{1 + x_0^T(X^TX)^{-1}x_0}$$
差别就在那个「1」

第一个公式就是 §26 取 $l = x_0$，只有估计 $\beta$ 的不确定性。第二个公式预测的是一个新的观测 $y_0 = x_0^T\beta + \epsilon_0$，还要加上 $\epsilon_0$ 本身的方差 $\sigma^2$，所以根号里多一个 1。$n$ 变大时，$x_0^T(X^TX)^{-1}x_0 \to 0$，置信区间缩成一条线，预测区间却不会小于 $\pm 1.96\sigma$。

29逐点 vs 同时置信

课件：Pointwise vs simultaneous

📝 课件原文

每个置信区间各自以 $1 - \alpha$ 的概率覆盖对应的真值 $x_0^T\beta$。把它们连起来，就是 $100(1-\alpha)\%$ 的逐点置信带（上一页的图）。

同时覆盖概率是指所有区间同时都覆盖各自真值的概率，要求严格得多。

直观理解

逐点置信带上，每个位置都有 5% 的机会没盖住，看很多位置时，「至少有一处没盖住」的概率远大于 5%。要让整条真实回归线以 95% 的概率完全落在带子里，带子必须更宽。上图金色的 Working–Hotelling 带就是一种做法：把 $t$ 分位数（1.98）换成 $\sqrt{p\,F_{p,n-p}} = \sqrt{2F_{2,109}} \approx 2.48$，这个换法来自 §30 的置信区域。

30置信区域（Confidence Region）

课件：Confidence Region、A Confidence Region for Air Quality（两页）

📝 课件原文

令 $A = I$、$c = \beta$，有

$$\frac{(\hat\beta - \beta)^TX^TX(\hat\beta - \beta)}{p\,\hat\sigma^2} \sim F_{p,\,n-p}$$

$\beta$ 的 $100(1-\alpha)\%$ 置信区域是所有满足 $(\hat\beta - \beta)^TX^TX(\hat\beta - \beta) \le p\,\hat\sigma^2F_{p,n-p}(1-\alpha)$ 的 $\beta$。$p = 2$ 时可以画成置信椭圆。置信区域考虑了系数估计值之间的相关性。

为什么是椭圆

不等式左边就是 L01 §2 讲的「换了一把尺子的距离」：用 $X^TX$ 当尺子量 $\beta$ 离 $\hat\beta$ 有多远（本质上是 Mahalanobis 距离，因为 $\mathrm{Var}(\hat\beta) \propto (X^TX)^{-1}$）。到中心「距离相等」的点组成椭圆，椭圆的主轴方向由 $X^TX$ 的特征向量决定（L01 §10）。

32ANOVA 与平方和的类型

课件：ANOVA、One-way vs Multi-way ANOVA、Types of Sum of Squares、Sequential Sum of Squares（两页）

📝 课件原文

用线性模型分析设计实验（因子）时，就叫方差分析（ANOVA）。它可以看成协变量都是类别变量的回归，用 $F$ 检验判断各组均值是否相等。

单因素 ANOVA：一个因子，多个水平。多因素 ANOVA：两个或以上因子，可能有交互。多因素时，平方和依因子进入模型的顺序不同，有不同的类型。

类型名称顺序有关吗衡量什么
Type I顺序 Sequential有关在已有因子基础上，加入这个因子后误差减少多少
Type II分层 Hierarchical无关控制所有其他主效应后这个因子的效应，忽略交互项
Type III偏 Partial无关控制模型里所有其他项后这个效应（主效应或交互）
顺序平方和的公式

记 $SS(x_1)$、$SS(x_1,x_2)$、$SS(x_1,x_2,x_3)$ 为三个嵌套模型的解释平方和：

$$SS_{x_1} = SS(x_1),\quad SS_{x_2\mid x_1} = SS(x_1,x_2) - SS(x_1) = SS_{error}(x_1) - SS_{error}(x_1,x_2)$$ $$SS_{x_3\mid x_1,x_2} = SS(x_1,x_2,x_3) - SS(x_1,x_2)$$ $$SS_{total} = SS_{x_1} + SS_{x_2\mid x_1} + SS_{x_3\mid x_1,x_2} + SS_{error}(x_1,x_2,x_3)$$

即把 $SS_{model}$ 拆成三份：$x_1$ 单独解释的；在 $x_1$ 基础上 $x_2$ 额外解释的；再加入 $x_3$ 额外解释的。拟合三个模型就能算出来，Type I 一次性给出全部（R 的 anova() 默认就是这个）。§24 的条形图就是它的样子。

「这是一个正交设计」是什么意思

每个「剂量 × 方式」组合正好 10 只豚鼠（平衡设计），所以代表 dose 和 supp 的列互相正交（L01 §2 的垂直）。各因子解释的部分互不重叠，Type I、II、III 平方和完全相同，顺序也无所谓。空气质量数据不是这样：Wind、Temp 相关，所以 §24 里顺序会改变结果。
