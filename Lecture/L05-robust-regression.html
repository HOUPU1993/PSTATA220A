1误差不是正态时

课件第 2 页：Robust methods + 手写

📝 课件原文
  • 假设 $y = X\beta + \epsilon$，但 $\epsilon$ 不是正态的。
  • 这时最小二乘就不那么合适了。OLS 只是正态残差下的 MLE。
  • 还有什么办法估计 $\beta$？
✍️ 手写
  • 「$\epsilon$ is non-Gaussian」旁边：$\epsilon \sim$ t-dist，$\epsilon \sim$ Laplace（例子）。
  • 「OLS is only the MLE」那句圈起来，连到下面的推导： $$Y_i \sim N(X\beta, \sigma^2),\qquad \text{Likelihood: } \prod_{i=1}^n\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(y_i - x_i\beta)^2}{2\sigma^2}}$$ $$\text{log-lik} \Rightarrow -\sum_{i=1}^n\frac{(y_i - x_i\beta)^2}{2\sigma^2}\quad\text{（Min. S.S. errors）}$$ $$\hat\beta \text{ is the maximum likelihood estimate (MLE)} \iff \hat\beta = \arg\min_\beta\sum_{i=1}^n\frac{(y_i - x_i\beta)^2}{2\sigma^2}$$
一步步看
  1. 独立观测的似然是各自密度的乘积；取对数后乘积变成求和。
  2. $\log\frac{1}{\sqrt{2\pi\sigma^2}}$ 和 $\beta$ 无关，扔掉；剩下 $-\sum(y_i - x_i\beta)^2/(2\sigma^2)$。
  3. 最大化「负的平方和」= 最小化平方和。所以 OLS 之所以「好」，是因为它恰好是正态误差下的最大似然估计。
  4. 反过来：误差换成别的分布，MLE 就会最小化别的东西。这就是本讲的出发点。

2分位数回归

课件第 3 页：Quantile Regression + 手写空白页

📝 课件原文
  • 到目前为止的一个关键假设是 $E[Y\mid X] = X\beta$。
  • 不对条件均值做假设，改为对条件分位数做假设： $$Q_{Y\mid X}(q) = \inf\{y : F_{Y\mid X}(y) \ge q\} = X\beta_q$$
  • $q = 0.5$（中位数回归）时，等价于最小化绝对误差。
  • R 里用 rq（quantreg 包）。
✍️ 手写
  • $E[Y\mid X] = X\beta$ 旁：Mean is linear in $X$；分位数公式下："conditional quantile"。
  • 空白页画了一张散点图，一条红线标 .25-quantile regression (assuming linear in $x$)。
  • $$\text{OLS: } \hat\beta = \arg\min_\beta\sum_{i=1}^n(y_i - x_i\beta)^2,\qquad \text{Median Regression } (q = 0.5)\text{: } \hat\beta = \arg\min_\beta\sum_{i=1}^n|y_i - x_i\beta|$$
  • 画了两条损失曲线：Sq. Error（绿，抛物线）和 Absolute Error (more robust)（橙，V 形），横轴是 Residual。
读分位数的定义

$F_{Y\mid X}(y)$ 是给定 $X$ 时 $Y$ 的累积分布函数。$Q_{Y\mid X}(q)$ 是「第一个让累积概率达到 $q$ 的 $y$」，比如 $q = 0.25$ 就是给定 $X$ 时的下四分位数。分位数回归假设这个分位数是 $X$ 的线性函数，系数 $\beta_q$ 随 $q$ 不同可以不同：「气温对臭氧最高的那 10% 天的影响」可以和「对中位数的影响」不一样。$\inf$ 是为了处理 $F$ 有跳跃（离散）的情形。

3Laplace 误差与中位数回归

手写空白页

✍️ 手写：Laplace ("double exponential") $$Y = X\beta + \epsilon,\quad \epsilon \sim \text{Laplace},\qquad L(\beta) \propto \prod e^{-|y_i - x_i\beta|}\ \Rightarrow\ \ell(\beta) = \sum|y_i - x_i\beta|$$

Median Regression：minimizes sum of absolute errors；MLE under a Laplace error model is median regression.

注意：少了一个负号

对数似然应为 $\ell(\beta) = -\sum|y_i - x_i\beta|$（再加一个和 $\beta$ 无关的常数）。最大化 $-\sum|\cdot|$ 等于最小化 $\sum|\cdot|$，所以结论不变，就是中位数回归。

和 §1 对照

Laplace 密度 $\frac{1}{2b}e^{-|\epsilon|/b}$ 的指数里是绝对值，正态的是平方。取对数后，正态 → 最小化平方和（OLS），Laplace → 最小化绝对值和（中位数回归）。Laplace 的尾巴比正态厚，「允许」偶尔出现大残差，所以它对应的估计不会为了迁就一个离群点而大幅移动。上面 §1 的右图就是这个对应关系。

4M 估计与损失函数

课件第 4–5 页：Robust Regression、Loss functions + 手写

📝 课件原文

稳健回归减小离群值的影响。用 M 估计最小化

$$\sum_{i=1}^n\rho\Big(\frac{y_i - \sum_{j=1}^p\beta_jx_{ij}}{s}\Big)$$

其中 $\rho$ 是某个函数，有多种选择（Huber、Hampel、bisquare 等）。Huber 损失：

$$L_\delta(a) = \begin{cases}\frac12a^2, & |a| \le \delta\\ \delta\cdot\big(|a| - \frac12\delta\big), & \text{otherwise}\end{cases}$$
✍️ 手写
  • Huber loss 下面（橙色）：Matches OLS up to $\delta$, then is linear like abs value loss.
  • 紫色 OLS 曲线旁：Quadratic (Heaviest penalty on outliers)。
  • 蓝色 Cauchy 曲线旁：Cauchy model of residuals。
读 Huber 公式
  • 「M」指 maximum-likelihood type：形式上像最大似然，但 $\rho$ 不一定来自某个真实分布。$\rho(u) = u^2/2$ 就是 OLS，$\rho(u) = |u|$ 就是中位数回归。
  • 除以 $s$（残差的尺度）是为了让 $\delta$ 有统一的含义：「超过几个标准差算大残差」。
  • Huber 的第二段 $\delta(|a| - \frac12\delta)$ 里减去 $\frac12\delta^2$，是为了在 $|a| = \delta$ 处和第一段值相等、斜率也相等（都等于 $\delta$），曲线平滑地接上。

5ψ 函数与 IRLS

手写空白页 + 课件第 6–7 页：Psi Functions

✍️ 手写 $$\hat\beta = \arg\min_\beta\sum_i\rho\Big(\frac{y_i - x_i\beta}{s}\Big)\qquad\text{Differentiate and set to 0.}$$ $$\frac{d}{d\beta}\sum_i^n\rho\Big(\frac{y_i - x_i\beta}{s}\Big) = \sum_i^n x_i\rho'\Big(\frac{y_i - x_i\beta}{s}\Big) = 0\qquad\text{Solve for }\beta.$$
📝 课件原文（老师高亮了公式框、$s$、rlm 和 MASS）

$\psi = \rho'$ 是损失函数的导数。$s$ 已知时，解方程

$$\sum_{i=1}^n x_i\,\psi\Big(\frac{y_i - \sum_{j=1}^p\beta_jx_{ij}}{s}\Big) = 0$$

得到 $\beta$ 的估计，其中 $x_i = (x_{i1}, \dots, x_{ip})^T$。这个方程可以用迭代重加权最小二乘（IRLS）求解。

  • 解依赖于尺度 $s$，而 $s$ 未知。简单的估计：先做一次初步拟合，用残差的中位数绝对偏差（MAD）。
  • 稳健回归在 MASS 包的 rlm 函数里。
注意：求导时的符号

对 $\beta$ 求导，链式法则会带出 $-x_i/s$，严格写是 $-\frac1s\sum x_i\rho'(\cdot)$。设为 0 时常数因子可以去掉，所以老师写的方程是对的，只是中间省略了这个因子。

为什么叫「迭代重加权最小二乘」
  1. 令 $u_i = (y_i - x_i\beta)/s$，定义权重 $w_i = \psi(u_i)/u_i$。则 $\psi(u_i) = w_iu_i$，方程变成 $\sum_i x_i\,w_i\,(y_i - x_i\beta) = 0$。
  2. 如果 $w_i$ 已知，这正是 WLS 的正规方程（L04 §7）：$X^TW(y - X\beta) = 0$，解是 $(X^TWX)^{-1}X^TWy$。
  3. 但 $w_i$ 依赖 $\beta$，所以轮流做：用当前 $\beta$ 算残差和权重 → 用这些权重做一次 WLS 得到新的 $\beta$ → 重复，直到不再变化。
  4. OLS 时 $\psi(u) = u$，权重全是 1，一步就到。Huber 时，$|u| \le k$ 的点权重为 1，大残差的点权重 $k/|u|$ 小于 1，被「降权」。
## MASS psi functions return psi(x)/x (the IRLS weight), so multiply by x to plot psi
huber_plt    <- ggplot() + geom_function(fun = \(x) x * MASS::psi.huber(x, k = 2), xlim = c(-3, 3))
hampel_plt   <- ggplot() + geom_function(fun = \(x) x * MASS::psi.hampel(x, a = 1, b = 2, c = 3), xlim = c(-3, 3))
bisquare_plt <- ggplot() + geom_function(fun = \(x) x * MASS::psi.bisquare(x, c = 2), xlim = c(-3, 3))

7Bootstrap 的想法

课件第 10–11 页 + 手写空白页

📝 课件原文 + ✍️ 手写

How can we generate confidence intervals for these robust regressions? 手写：(without assuming distributions of errors) → Bootstrap

  • Resample my data with replacement，same sample size, $n$, as original（有放回地重抽数据，样本量和原来一样）。
  • Compute $\hat\beta$ on that resampled set.
  • Do many times!
✍️ 手写空白页

$\hat\beta^{(1)}, \hat\beta^{(2)}, \dots, \hat\beta^{(S)}$：$S$ new estimates of $\hat\beta$.

Claim: Those $\hat\beta^{(i)}$ samples approximate the sampling distribution of $\hat\beta$.

画了一张图：柱子是 Histogram of actual sample，绿色曲线是 True data generating distribution for $y$。

Empirical Distribution of data approximates the population distn when $n$ is large!

为什么这样做有道理

$\hat\beta$ 的抽样分布是「从总体反复抽样本、每次算一个 $\hat\beta$」得到的分布。我们只有一份样本，没法再从总体抽。Bootstrap 的替换：用经验分布代替总体。从经验分布抽样，就是从手上的 $n$ 个观测里有放回地抽 $n$ 个。只要经验分布和总体足够接近（$n$ 够大），「从经验分布重抽得到的 $\hat\beta$ 的散布」就接近「从总体重抽得到的散布」。它不需要知道误差服从什么分布，也不需要推导方差公式，所以对 Huber、中位数回归这种没有简单公式的估计量特别有用。

📝 课件原文（第 11 页）

Bootstrap：构造置信区间的非参数方法；在数学上难以推导估计量的分布、或样本很小时有用。两种 bootstrap：

  1. Random-x：$y$ 和 $x$ 一起重抽（「配对」bootstrap）。
  2. Fixed-x：重抽残差，生成新的 bootstrap 样本（「残差」bootstrap）。

8配对 bootstrap（Random-x）

课件第 12–14 页：Paired Bootstrap（这周没有批注）

📝 课件原文

生成一组新的 IID 观测 $(X_1^*, Y_1^*), \dots, (X_n^*, Y_n^*)$，其中

$$P(X_\ell^* = X_i,\ Y_\ell^* = Y_i) = \frac1n,\quad \forall i = 1, \dots, n$$

重复 $B$ 次，得到 $B$ 份 bootstrap 样本。

library(tidyverse); library(tidymodels)
bootstrap_models <- airquality %>% drop_na %>% bootstraps(times = 100) %>%
  mutate(lm_fit = map(splits, ~ lm(Ozone ~ Solar.R + Temp, data = .x)),   # refit on each resample
         coefs  = map(lm_fit, tidy))

bootstrap_models %>% unnest(cols = coefs) %>% group_by(term) %>%
  summarize(mean  = mean(estimate),
            lower = quantile(estimate, 0.025),     # percentile interval
            upper = quantile(estimate, 0.975))
#   term          mean    lower   upper
# 1 (Intercept) -146.    -177.   -120.
# 2 Solar.R        0.0539   0.0165  0.0951
# 3 Temp           2.29     1.92    2.68

airquality %>% drop_na() %>% lm(Ozone ~ Solar.R + Temp, data = .) %>% confint()
#                  2.5 %      97.5 %
# (Intercept) -182.2677   -109.1386
# Solar.R        0.00613     0.1081
# Temp           1.79086     2.7661
代码在做什么
  • bootstraps(times = 100) 生成 100 份重抽样本（每份是一组行号）；map 对每一份重新拟合 lm；tidy 把系数整理成表。
  • 百分位数区间：把 100 个估计排序，取第 2.5% 和 97.5% 分位数。
  • 课件中间那张表 bootstrap_models$coefs[[2]] 是第 2 份 bootstrap 样本上的拟合结果（Solar.R 只有 0.0038），说明单份重抽的结果可以离原估计很远，要看的是很多份的整体分布。
  • 100 次对 95% 区间来说偏少（两端各只有 2–3 个点决定区间端点），实际中常用 1,000 次以上。

9残差 bootstrap（Fixed-x）

课件第 15–20 页：Residual Bootstrap（这周没有批注）

📝 课件原文

先生成 IID 的 $\hat\epsilon_1^*, \dots, \hat\epsilon_n^*$，每个满足 $P(\hat\epsilon_\ell^* = e_i) = \frac1n$，$\forall i = 1, \dots, n$；再生成新样本

$$X_i^* = X_i,\qquad Y_i^* = \hat\beta_0 + \hat\beta_1X_i + \hat\epsilon_i^*$$
注意：课件的小笔误

课件写的是「$\forall n = 1, \dots, n$」，应为 $\forall i = 1, \dots, n$。

和配对 bootstrap 的区别
  • $x$ 固定不动（Fixed-x），只重抽残差，再加回到拟合值上，造出新的 $y$。
  • 它隐含的假设是：残差可以在不同的 $x$ 之间互换，即误差和 $x$ 无关、同分布（同方差）。这和经典回归的假设一致，所以当假设成立时，它比配对 bootstrap 更稳定。
  • 假设不成立（异方差）时，它会和经典标准误一样出错，见下图。
air <- airquality %>% drop_na
airquality_lm <- air %>% lm(Ozone ~ Solar.R + Temp, data = .)   # fit once to get coefs and residuals
air$residual <- airquality_lm$residuals
air$fitted   <- airquality_lm$fitted.values

residual_bootstraps <- air %>% dplyr::select(residual) %>% bootstraps(times = 100)   # resample residuals only

boot_coefs <- residual_bootstraps |>
  mutate(splits = map(splits, ~ bind_cols(air %>% select(-residual), as_tibble(.x)) %>%
                                mutate(Ozone = fitted + residual))) %>%      # new y = fitted + resampled residual
  mutate(lm_fit = map(splits, ~ lm(Ozone ~ Solar.R + Temp, data = .x)),
         coefs  = map(lm_fit, tidy))
#   term          mean    lower    upper
# 1 (Intercept) -142.    -180.    -118.
# 2 Solar.R        0.0583   0.00653  0.111
# 3 Temp           2.23     1.89     2.76
课件里两个中间输出
  • <split [111/39]>：见 §8 最后一张图。
  • cbind(...$data, ...$in_id)：左列是原来的残差（按原顺序），右列 in_id 是第 1 份 bootstrap 样本抽中的行号（36、29、85……，有重复，比如 31 出现了两次）。新的第 $i$ 个残差就是原来第 in_id[i] 个残差。
注意：第 19 页那段演示代码

代码里先算了 ynew <- fitted_values + residuals[indices]（这才是残差 bootstrap），但最后拟合的是 lm(y[indices] ~ x)：只打乱了 $y$、没动 $x$，等于把 $x$ 和 $y$ 的配对随机拆开，所以输出的斜率是 −0.013（接近 0），并不是 bootstrap 估计。按残差 bootstrap 应该是 lm(ynew ~ x)，按配对 bootstrap 应该是 lm(y[indices] ~ x[indices])。这段数据（y <- rnorm(n, x, sd = abs(x))）本身是强异方差的，正好可以用来比较两种 bootstrap。

10覆盖率模拟

课件第 23 页：Coverage Simulation

sample_size <- 20; beta <- 1; nsims <- 1000
covers_vec <- numeric(nsims)
for (i in 1:nsims) {
  x <- rnorm(sample_size)
  y <- beta * x + rt(sample_size, df = 3)        # heavy-tailed errors
  lm_fit <- lm(y ~ x)                              # residuals from an OLS fit
  res_boots <- tibble(residuals = lm_fit$residuals) |> bootstraps(times = 100)
  bootstrap_reps <- res_boots |>
    mutate(splits = map(splits, ~ tibble(x = x, fitted_values = lm_fit$fitted.values,
                                         residual = as_tibble(.x)$residuals) |>
                                  mutate(y = fitted_values + residual))) %>%
    mutate(lm_fit = map(splits, ~ MASS::rlm(y ~ x, data = .x)),   # robust fit on each resample
           coefs  = map(lm_fit, tidy))
  est_vec <- map_vec(bootstrap_reps$coefs, ~ as.numeric(.x[2, "estimate"]))
  covers_vec[i] <- beta > quantile(est_vec, 0.025) & beta < quantile(est_vec, 0.975)
}
mean(covers_vec)   # 0.879
这段模拟在检验什么

「95% 置信区间」的定义是：重复很多次，区间盖住真值的比例应当是 95%（L03 §6）。这里真值 $\beta = 1$ 已知，于是可以直接数：1,000 次里有多少次 bootstrap 区间盖住了 1。结果 0.879，说明在 $n = 20$ 的小样本下，这种「OLS 残差 + 残差 bootstrap + rlm + 百分位数区间」的组合给出的区间偏窄。

11Bootstrap 不是万能的

课件第 24 页：The bootstrap is not a panacea

📝 课件原文
  • Bootstrap 有很多不同的变体。
  • 「朴素」bootstrap 对相关的数据无效。
  • 「朴素」bootstrap 对有约束的参数或极值无效。
  • 还有很多其他例子……
为什么
  • 相关数据：朴素 bootstrap 把每个观测独立地抽，打散了时间或群内的依赖结构，等于假设了独立，会像 L04 §4–§5 的经典标准误一样低估不确定性。补救：按块（block bootstrap）或按群（cluster bootstrap）整体重抽。
  • 极值：见下图。
  • 有约束的参数：比如真值正好在边界上（方差 = 0），估计量的分布在边界处被截断，bootstrap 也模仿不好。

12基于模型的稳健回归

课件第 21–22、25 页：Model based perspectives、Model Based Approaches to Robust Regression

📝 课件原文

基于模型的稳健回归：Laplace 回归、$t$ 回归、$\epsilon$-污染模型。

思路：不改损失函数，改误差分布
  • Laplace 回归：假设误差服从 Laplace，MLE 就是中位数回归（§3）。
  • $t$ 回归：假设误差服从 $t_\nu$，MLE 的损失 $-\log f$ 按对数增长（§1 右图），大残差的影响有上限。课件源文件末尾有一段被注释掉的 $t$ 回归代码，用 optim 最大化 $\sum\log\big[\frac1\sigma f_{t_\nu}\big(\frac{y_i - x_i\beta}{\sigma}\big)\big]$。
  • $\epsilon$-污染模型：假设大部分数据（比例 $\pi$）来自正常的回归模型，少部分来自一个很散的「污染」分布： $$f(y_i) = \pi\,N(y_i;\ \beta_0 + \beta_1x_i,\ \sigma_1^2) + (1 - \pi)\,N(y_i;\ 0,\ \sigma_2^2)$$

好处是有完整的似然，可以算标准误、比较模型；拟合后每个点还能得到「属于污染成分」的概率。

neg_log_likelihood <- function(params) {
  beta_0 <- params[1]; beta_1 <- params[2]
  sigma_clean <- exp(params[3])            # log scale keeps sigma positive
  sigma_contaminated <- exp(params[4])
  pi <- plogis(params[5])                  # logit scale keeps pi in (0, 1)
  d_clean <- dnorm(y, mean = beta_0 + beta_1 * x, sd = sigma_clean, log = TRUE)
  d_contaminated <- dnorm(y, mean = 0, sd = sigma_contaminated, log = TRUE)
  -sum(log(pi * exp(d_clean) + (1 - pi) * exp(d_contaminated)))   # mixture likelihood
}
fit <- optim(c(1, 1, log(1), log(10), qlogis(0.9)), neg_log_likelihood, method = "BFGS", hessian = TRUE)
# Estimated beta_0: 1.943   beta_1: 0.964   sigma (clean): 3.171
# sigma (contaminated): 23.84   mixing probability (pi): 0.920
代码里的两个技巧

$\sigma$ 必须为正、$\pi$ 必须在 (0, 1) 之间，但 optim 做的是无约束优化。所以让它优化 $\log\sigma$ 和 $\mathrm{logit}(\pi)$，再用 exp、plogis 变回来。hessian = TRUE 返回负对数似然的二阶导数矩阵，它的逆就是参数（在变换后的尺度上）的近似协方差矩阵，可以用来算标准误。

13变量含误差（Errors-in-Variables）

课件第 26 页

📝 课件原文
  • 假设只能观测到协变量的带噪声版本 $\check X = X + E_X$。设 $E[\mathcal E_X] = 0$，$\mathrm{Cov}(X, \mathcal E_X) = 0$，$\mathrm{Cov}(Y, \mathcal E_X) = 0$。
  • 拟合模型 $Y = \check X^\top\check\beta_{err} + \epsilon_Y$。$\hat\beta_{err}$ 和 $\hat\beta$ 相比如何？
简单回归时的答案

斜率估计是 $\widehat{\mathrm{Cov}}(\check X, Y)/\widehat{\mathrm{Var}}(\check X)$。由假设，

$$\mathrm{Cov}(\check X, Y) = \mathrm{Cov}(X, Y) + \underbrace{\mathrm{Cov}(E_X, Y)}_{0},\qquad \mathrm{Var}(\check X) = \mathrm{Var}(X) + \mathrm{Var}(E_X)$$ $$\Rightarrow\ \hat\beta_{err} \to \frac{\mathrm{Cov}(X, Y)}{\mathrm{Var}(X) + \mathrm{Var}(E_X)} = \beta\cdot\frac{\mathrm{Var}(X)}{\mathrm{Var}(X) + \mathrm{Var}(E_X)}$$

分子不变，分母多了噪声的方差，所以斜率被压向 0（衰减偏误）。直觉：$\check X$ 的波动里有一部分是纯噪声，和 $Y$ 毫无关系，「稀释」了 $X$ 和 $Y$ 的关系。注意 $y$ 上的噪声只会让估计更不精确，不会造成偏差；$x$ 上的噪声会造成偏差。

14总体最小二乘（Total Least Squares）

# plot: blue = b_x, red = 1 / b_y, dark green = beta_tls
为什么 TLS 是第一主成分

点 $z_i$ 到过原点、方向为单位向量 $v$ 的直线的垂直距离平方是 $\|z_i\|^2 - (v^Tz_i)^2$（勾股定理，L01 的投影）。对所有点求和后，最小化距离等于最大化 $\sum(v^Tz_i)^2 = v^T(Z^TZ)v$，答案是 $Z^TZ$ 最大特征值对应的特征向量，也就是第一主成分方向。当 $x$ 和 $y$ 的测量误差方差相同时，TLS 能修正 §13 的衰减偏误；两个方差不同时要先缩放（Deming 回归）。
